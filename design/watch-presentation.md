# 시계 공통 프레임 + 발표 모드 화면 명세

2026-10-16 · 디자인팀 2번 · 기준: `../손목컨트롤러_작업지시서.md`, `system.md`, `tokens.css`, `icons.svg`
목업: `mockups/watch-presentation.html` (로컬 서버로 열지 않아도 동작하도록 아이콘을 인라인으로 넣음)

이 문서는 `system.md` 3.1·3.2·3.5·3.6·5절을 구현 가능한 수준으로 펼친 것이다. 색·크기·시간은 모두 `tokens.css` 토큰 이름으로 적는다. `system.md`와 다르게 정한 곳은 **[시스템과 차이]**, 토큰에 없는 값을 새로 쓴 곳은 **[토큰 제안]**으로 표시했다. 판정 시간·임계값의 원본은 `/shared` 설정 파일이고, 이 문서의 값은 디자인 기본값이다.

좌표는 화면 왼쪽 위 (0,0) 기준 px, 표기는 `x, y, w, h`.

### 1.4 모드 인디케이터 점 — 가운데 정렬, 중심 y 470

- 순서: 발표 · 코딩 · 회의 (왼→오). 순환 전환이지만 점은 순환하지 않고 고정 위치.
- 활성: `24 × 8` 알약(반경 pill) `--wc-accent`. 비활성: `8 × 8` 원 `--wc-text-disabled`.
- 간격 12. 전체 폭 24+12+8+12+8 = 64 → `x 173~237, y 466~474`.
  - 발표 활성: 알약 x 173, 점 x 209, 229
  - 코딩 활성: 점 x 173, 알약 x 193, 점 x 229
  - 회의 활성: 점 x 173, 193, 알약 x 213
- 전환 애니메이션: 알약 이동 대신 **교차 페이드** `--wc-motion-fast`(120ms). (폭 변화는 transform이 아니므로 피한다.)
- 터치 없음. 끊김 배너·시트가 뜨면 가려진다(별도 숨김 처리 불필요).

### 1.5 좌우 스와이프 모드 전환

| 항목 | 값 |
| --- | --- |
| 시작 영역 | 본문 y 64~486 어디서나 |
| 판정 | 가로 이동 ≥ 80px **그리고** 세로 이동 < 60px (system 3.5). 또는 가로 속도 ≥ 0.5 px/ms 이고 가로 ≥ 40px **[토큰 제안: `/shared` 에 `swipe_min_px 80`, `swipe_max_off_axis_px 60`, `swipe_fling_px_per_ms 0.5`]** |
| 방향 | 왼쪽으로 밀기(손가락 ←) = 다음 모드(발표→코딩→회의→발표), 오른쪽으로 밀기 = 이전 모드 |
| 손가락 따라오기 | 가로 이동 16px 넘는 순간부터 본문 레이어가 손가락을 1:1로 따라온다(이웃 모드 본문이 옆에서 보임). 이때 진행 중이던 탭 판정은 취소 |
| 손 뗌 → 확정 | 남은 거리를 `--wc-motion-mode`(280ms) `--wc-ease-out`으로 마저 이동 |
| 손 뗌 → 취소 | 제자리로 `--wc-motion-release`(160ms) `--wc-ease-out` |
| 상태줄 | 움직이지 않는다. 확정 순간 모드 점·이름·점 인디케이터를 120ms 교차 페이드로 새 모드색·이름으로 바꾼다 |
| 모드 이름 오버레이 | 확정 순간 화면 가운데(`0, 227, 410, 48`)에 title(40/48/700) `--wc-accent` 새 모드 이름. 0→1 120ms, 유지, 600ms 시점부터 1→0 200ms. 터치 통과 |
| 키 전송 | 스와이프는 키를 보내지 않는다. 마지막 모드는 NVS 저장(지시서) |
| 금지 | 쇼 시트가 열려 있거나 에어마우스 중에는 스와이프 무시 |

펌웨어(LVGL): 본문 3개를 가로로 붙인 컨테이너 하나의 `x`만 `lv_anim`으로 움직인다. 순환이므로 확정 후 컨테이너를 재배치해 현재 모드를 가운데로 돌려 놓는다.

### 1.6 공용 토스트 틀

`45, 215, 320, 72`, 반경 `--wc-radius-md`, 테두리 2px, 아이콘 28 (`x+20`, 세로 가운데), 글자 body(26/32/600) `--wc-text-1` (`x+60`). 등장 opacity 0→1 + translateY 8→0, `--wc-motion-base`. 유지 `--wc-motion-toast`(1600ms). 퇴장 opacity 200ms. 터치 통과(아래 입력을 막지 않는다). 동시에 하나만, 새 토스트가 오면 즉시 교체.

## 2. 발표 모드 본문

### 2.1 영역 (본문 y 64~486, 모두 화면에 선을 그리지 않는 보이지 않는 영역)

| 영역 | 좌표 | 짧은 탭 | 길게 누름 |
| --- | --- | --- | --- |
| 왼쪽 | `0, 64, 120, 422` | 이전 `←` | 없음 |
| 중앙 | `120, 64, 170, 422` | 없음(무시) | 600ms → 암전 `B` |
| 오른쪽 | `290, 64, 120, 422` | 다음 `→` | 없음 |

**[시스템과 차이] 좌우 탭은 손을 뗄 때 보낸다.** system 5절은 "누르는 순간 전송"이지만, 발표 화면은 전체가 스와이프 시작 영역이라 누르는 순간 보내면 모드를 바꾸려던 스와이프가 슬라이드를 넘겨 버린다. 판정: 이동 < 16px 이고 누른 시간 < 600ms 이면 손을 뗄 때 즉시 전송. 탭은 보통 80~120ms라 지연 목표(100ms) 안팎이다. 다른 모드(코딩·회의 타일)는 system 규칙(누르는 순간 전송)을 그대로 따른다.

### 2.2 요소 배치

| 요소 | 좌표 | 스타일 |
| --- | --- | --- |
| 음성 띠 | `95, 64, 220, 32` | 2.6절 |
| 쇼 상태 라벨 | `0, 152, 410, 28` 가운데 | label `--wc-text-2`: "쇼 시작 전" / "쇼 진행 중" / "쇼 끝남" |
| 경과 시간 | `0, 196, 410, 112` 가운데 (기준선 ≈ y 300) | display(112/112/700) tabular-nums |
| 암전 칩 | `135, 330, 140, 44` | 2.4절 |
| 탭 힌트 왼쪽 | `40, 418, 80, 24` 왼쪽 정렬 | caption `--wc-text-3` "‹ 이전" |
| 탭 힌트 중앙 | `120, 418, 170, 24` 가운데 | caption `--wc-text-3` "길게 · 암전" (암전 중: "길게 · 복귀") |
| 탭 힌트 오른쪽 | `290, 418, 80, 24` 오른쪽 정렬 | caption `--wc-text-3` "다음 ›" |
| 모드 점 | 1.4절 | |

힌트 글자는 각 영역 안에 있으므로 "어디를 누르면 무엇"을 화면을 보지 않고 외우기 쉽다. 영역 경계선은 그리지 않는다(발광 면적·시선 분산 최소화).

### 2.3 경과 시간

| 상태 | 표시 | 색 |
| --- | --- | --- |
| 쇼 시작 전 | `00:00` | `--wc-text-3` |
| 쇼 진행 중 | `mm:ss` 매초 갱신 | `--wc-text-1` |
| 쇼 끝남(Esc 보냄) | 멈춘 값 유지 | `--wc-text-2` |
| 연결 끊김 | 계속 흐름 | `--wc-text-3` (system 5.1) |

- 시작: 시트의 "쇼 시작"(F5)을 보낸 순간 00:00부터. 시트를 거치지 않고 PC에서 직접 쇼를 시작했으면 **첫 "다음/이전" 전송 순간** 자동 시작(쇼 시작 전 상태에서만).
- 종료: "쇼 종료"(Esc)를 보내면 멈춤. 다음 "쇼 시작" 때 00:00으로 초기화.
- 60분 넘으면 시(時)로 넘기지 않고 분을 계속 센다(`75:12`). 99:59에서 멈춤. 다섯 글자 폭을 넘지 않아 112px 한 줄 유지.
- 다른 모드로 가도 타이머는 계속 돈다. 글자 폭이 바뀌지 않도록 tabular-nums 필수(펌웨어 폰트도 숫자 고정폭으로 변환).
- 펌웨어 폰트: 112px은 `0-9 :` 11글자만.

### 2.4 탭 피드백과 암전

**좌/우 탭(전송 성공)**: 해당 영역 전체(`0,64,120,422` 또는 `290,64,120,422`)에 `--wc-accent-dim` 면을 opacity 1로 띄웠다가 `--wc-motion-flash`(400ms) `--wc-ease-out`으로 0까지. 화면 전체를 밝게 채우지 않는다(system 5.3). 측면 버튼 1회·손목 튕김·음성 "다음"으로 보낸 `→`도 **같은 오른쪽 영역 플래시**를, 안쪽 튕김 `←`는 왼쪽 플래시를 쓴다 → 입력 경로와 무관하게 "어느 쪽으로 넘겼나"가 같은 모양.

**중앙 길게 누름 진행**: 누른 순간부터 중앙 영역(`120,64,170,422`)에 `--wc-accent-dim` 면이 opacity 0→1로 600ms 선형 증가(`--wc-hold-center`). 600ms 전에 떼거나 16px 이상 움직이면 160ms에 0으로 되돌림(전송 없음). 600ms 도달 순간 `B` 전송 → 면이 400ms 동안 0으로 사라짐(플래시).

**암전 상태**: `B`는 PC에서 토글이라 시계는 "마지막으로 보낸 B의 홀짝"으로만 안다(HID 단방향).
- 암전 중 칩: `135, 330, 140, 44`, 면 `--wc-surface-2`, 반경 `--wc-radius-sm`, 글자 label `--wc-accent` "암전 중", 가운데.
- 중앙 힌트가 "길게 · 복귀"로 바뀐다.
- 다음/이전·쇼 종료를 보내면 PowerPoint는 암전이 풀리므로 칩을 자동으로 지운다.
- 칩 등장/퇴장: opacity `--wc-motion-base`.

### 2.5 에어마우스 (측면 버튼 누른 채)

**버튼 판정 (디자인 제안, 원본은 `/shared`)** — 같은 측면 버튼이 "1회=다음", "누른 채=에어마우스", "2초=잠금 토글" 세 가지를 맡으므로 다음 순서로 가른다. **[토큰 제안: `airmouse_hold_ms 250`]**

| 누른 시간 | 결과 |
| --- | --- |
| < 250ms 에 뗌 | 다음 `→` (오른쪽 영역 플래시) |
| ≥ 250ms | 에어마우스 시작 (아래 화면) |
| 2000ms 동안 커서 이동량이 데드존 안 | 잠금 토글 (`--wc-hold-side`). 1000ms 시점부터 링 색이 `--wc-locked`로 교차 페이드(1000ms 동안 opacity) → 2000ms에 토글·토스트, 그 뒤엔 손을 뗄 때까지 아무것도 보내지 않음 |
| 2000ms 안에 손목을 움직임 | 잠금 판정 취소, 에어마우스 계속 |

발표 외 모드에서는 에어마우스가 없으므로 2000ms 길게 누름 = 잠금만 판정.

**화면 (에어마우스 중)**
| 요소 | 좌표 | 스타일 |
| --- | --- | --- |
| 경과 시간·쇼 상태·힌트 | — | opacity 0 (120ms). 손을 떼면 120ms로 복귀 |
| 포인터 링 | `125, 180, 160, 160` 원, 중심 (205, 260) | 테두리 3px(`--wc-focus-ring`) `--wc-accent`, 면 없음 |
| 링 중앙 점 | `199, 254, 12, 12` 원 | `--wc-accent` |
| 라벨 | `0, 352, 410, 28` 가운데 | label `--wc-accent` "포인터" |
| 안내 | `0, 388, 410, 24` 가운데 | caption `--wc-text-2` "화면 탭 = 클릭" |
| 음성 띠·모드 점·상태줄 | 그대로 | |

- 진입: 링 scale 0.9→1 + opacity 0→1, `--wc-motion-base`(200ms).
- 화면 어디든 탭 = 마우스 왼쪽 클릭(누르는 순간 down, 뗄 때 up). 피드백: 링 안쪽을 `--wc-accent-dim` 원으로 채웠다가 400ms 페이드 + 링 scale 0.96(80ms) → 1(160ms).
- 버튼을 놓는 즉시 커서 이동 정지, 링은 opacity 200ms로 사라짐. 화면 애니메이션을 기다리지 않는다.
- 커서 위치를 링 안에서 움직여 보여 주지 않는다(시계는 PC 커서 위치를 모름, 그리기 비용).
- 에어마우스 중 좌우 스와이프·아래 스와이프·중앙 길게 누름은 무시.

### 2.6 음성 "키트" 호출 피드백 — 음성 띠 `95, 64, 220, 32`, 반경 pill

| 상태 | 띠 면 | 아이콘(28, 왼쪽 x+10) | 글자(caption, x+44) | 애니메이션 |
| --- | --- | --- | --- | --- |
| 꺼짐 (잠금 중 또는 설정에서 음성 끔) | 표시 안 함 | — | — | — |
| 대기: 호출어 "키트" 듣는 중 | 없음(검정) | `i-voice` `--wc-text-3` | `--wc-text-3` "‘키트’ 대기" | 없음 (상시 표시라 정지 화면, 절전) |
| 호출어 인식: 명령 듣는 중 | `--wc-accent-dim` + 1px `--wc-accent-dim-border` | `i-voice` `--wc-accent` | `--wc-text-1` "듣는 중…" | 등장 120ms. 띠 아래 안쪽에 2px `--wc-accent` 진행선이 scaleX 1→0으로 3000ms 동안 줄어듦 **[토큰 제안: `voice_command_window_ms 3000`, `/shared`]** |
| 명령 인식 "다음" (연결됨) | 같음 | `--wc-accent` | `--wc-text-1` "다음 →" | `→` 전송 + 오른쪽 영역 플래시. 600ms 후 대기로 120ms 페이드 |
| 명령 인식 (끊김 중) | `--wc-disconnected-dim` + 1px `--wc-disconnected` | `--wc-disconnected` | `--wc-text-1` "보내지 않음" | 띠 가로 ±6px 2회 흔들림 400ms (끊김 배너 규칙과 동일), 600ms 후 대기 |
| 시간 초과 / 모르는 말 | — | — | — | 대기로 200ms 페이드. 실패 표시는 하지 않는다(발표 중 주의 분산 방지) |

- "다음" 단독(호출어 없이)은 **아무 피드백도 없다**. 띠가 반응하지 않는 것 자체가 "무시됨"을 뜻한다.
- 띠는 발표 모드에만 있다(음성 명령은 발표 모드 기능).
- 시뮬레이션 사이트에서는 띠 바깥(시계 밖)에 `--sim-notice-*` 안내 띠로 "실제 시계 음성 엔진과 무관"을 표시(시뮬레이션팀 몫).

### 2.7 제스처·음성 잠금

- 상태줄 `244,14` 에 `i-lock` `--wc-locked` 상시 표시.
- 음성 띠 숨김(꺼짐 상태). 손목 튕김 무시.

## 6. 구현 메모

- **LVGL 9**: 영역 플래시는 `lv_obj` 하나(면 accent-dim, `LV_OPA_COVER`)의 `opa`를 `lv_anim`. 중앙 진행도 같은 방식. 링은 `border_width 3`, `radius LV_RADIUS_CIRCLE`. 점멸은 `lv_timer` 500ms로 `LV_OBJ_FLAG_HIDDEN` 토글(애니메이션 아님 → 전력 최소).
- **다시 그리기 최소화**: 매초 바뀌는 것은 경과 시간 라벨 하나뿐. 시각·배터리는 분 단위/5% 단위.
- **번인**: 경과 시간은 같은 자리에 오래 떠 있다. 10분마다 본문 전체를 ±2px 이동(시계 방향 순환)하는 픽셀 이동을 권한다(눈에 띄지 않음). 상태줄도 함께 이동.
- **화면 자동 꺼짐 직전 5초**: 전체 opacity .5 (system 5.3). 발표 모드에서 쇼 진행 중이면 자동 꺼짐 시간을 설정값보다 길게(예: 60초) 두는 것을 제안 — 전원 관리 담당과 협의.
- **시뮬레이터**: 목업 HTML의 클래스·좌표를 그대로 옮겨도 된다. 아이콘은 `icons.svg` 원본을 쓰고, 목업처럼 인라인 사본을 두지 않는다.
