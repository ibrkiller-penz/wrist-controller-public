# 설정 화면 · 시뮬레이터 설정 패널 · 시계에 설치 페이지

2026-10-16 · 디자인팀 5번 · 기준: `../손목컨트롤러_작업지시서.md`, `system.md`, `tokens.css`, `icons.svg`
목업: `mockups/settings.html` (로컬 서버로 열 것 — `python -m http.server` 후 `/design/mockups/settings.html`. `file://`로 열면 아이콘 `<use>`가 막힌다)

이 문서는 네 가지를 다룬다.

1. 시계 안 설정 화면 (에어마우스 감도 3단계, BLE 장치 이름, OS 선택, 펌웨어 버전)
2. 시뮬레이터 설정 패널 (`keymap.json`·`gesture.json` 편집, 제스처 튜닝 실시간 그래프)
3. "시계에 설치" 페이지 (ESP Web Tools)
4. "음성 시뮬레이션은 실제 시계 음성 엔진 정확도와 무관" 고지 배치

색·글자·간격·모션은 모두 `tokens.css` 토큰 이름으로 적는다. 새 토큰은 만들지 않았다. 아이콘은 `icons.svg`에 있는 것만 쓰고, 없는 기호(✓ ‹ ›)는 글자로 쓴다.
JSON 필드 이름(`thresholdDps` 등)은 **가정**이다. `/shared` 스키마 담당이 정한 이름이 나오면 그쪽을 따르고 이 문서를 고친다.

자유 입력은 시계에서 하지 않는다(410px에 한글 키보드는 비현실적). **미리 정한 이름 3개 + 기기 고유 끝자리** 방식.

| 요소 | x, y, w, h | 스타일 |
| --- | --- | --- |
| 제목 "블루투스 이름" | 24, 64, 362, 40 | heading 32/40 |
| 후보 행 ×3 | 16, **108 / 200 / 292**, 378×88, 간격 4 | `--wc-surface-1`, 반경 md. 이름 body, 끝자리 `-1A2B` caption mono `--wc-text-3` |
| 선택 표시 | 행 오른쪽 x 346, 28×28 | "✓" body `--wc-accent` + 행 면 `--wc-accent-dim` + 3px `--wc-accent` 테두리 |
| 취소 | 16, 392, 378×88 | `--wc-surface-1`, "취소" body |

- 후보(예시): `WristCtrl`, `Kit Remote`, `손목 리모컨`. 실제 광고 이름 = 후보 + `-` + BLE MAC 끝 4자리(대문자 hex). 여러 시계가 있어도 PC 목록에서 구분된다.
- 이름 길이 상한 **UTF-8 24바이트**(한글 1자 = 3바이트). 광고 패킷이 31바이트라 이름은 스캔 응답에 넣는다(펌웨어팀 확인). macOS·Windows에서 한글 이름 표시 여부는 2단계에서 실기 확인, 깨지면 한글 후보를 뺀다.
- 화면 전환: 설정 목록 위로 오른쪽에서 280ms 슬라이드. 오른쪽 스와이프 = 취소.
- 자유 문자열 이름은 1차 범위 밖. 필요하면 시뮬레이터 패널에서 정해 빌드에 넣는 방식(스키마 담당과 논의).

## 2. 시뮬레이터 설정 패널

### 2.1 위치와 크기

- 시뮬레이터 상단 바의 `i-gear` 버튼(40×40, 아이콘 20px, `--sim-text-2`)으로 연다. 단축키는 두지 않는다(Space는 측면 버튼 흉내라 충돌 위험).
- **오른쪽 서랍**: 너비 560px, 높이 100vh, `--sim-surface`, 왼쪽 1px `--sim-border`, `--sim-shadow`. 가운데 가상 PC 화면 위를 덮고, **왼쪽 시계 에뮬레이터는 가리지 않는다** — 바꾼 값이 시계에 즉시 반영되는 것을 보면서 고치게 하려는 것.
- 열기·닫기: `transform: translateX` 200ms(`--wc-motion-base` 값 재사용) `--wc-ease-out`. Esc로 닫힘(포커스가 JSON 편집기 안이 아닐 때).
- 화면 너비 < 1100px: 전체 화면 덮개로 바뀐다. 시계 미리보기는 패널 맨 위에 작게(축척 0.5, 205×251) 고정.
- 테마: `--sim-*` 라이트/다크를 따른다.

### 2.3 keymap.json 폼

- 모드 선택 세그먼트: 발표 / 코딩 / 회의. 각 버튼 앞 8px 점에 `--sim-mode-*` 색. 회의를 고르면 아래에 앱 선택 [Zoom | Teams | Meet].
- 동작 표(행 높이 48):

| 열 | 너비 | 내용 |
| --- | --- | --- |
| 기능 | 140 | 라벨 입력칸(시계 타일 라벨). 5글자 초과 경고 |
| Windows | 150 | 단축키 입력칸, `--sim-font-mono` 14px |
| macOS | 150 | 같음 |
| 상태 | 나머지 | 오류·경고 아이콘 글자(● / ▲) |

- **단축키 입력칸**: 클릭하면 "키를 누르세요…" 자리표시 + `--sim-focus` 2px 링. 다음 키 조합을 잡아 `Ctrl+Shift+P` 형식으로 넣는다. 직접 타이핑도 허용. Backspace 단독 = 비우기, Esc = 취소.
- 칸을 비우면 시계에서 그 타일이 **비활성**으로 그려진다는 안내를 행 아래 12px `--sim-text-3`로 표시.

### 2.4 검증과 즉시 반영

- 입력이 멈추고 **300ms 뒤** 검증한다. **오류가 0개일 때만** 시계 에뮬레이터·가상 PC에 즉시 반영. 오류가 있으면 마지막으로 유효했던 설정을 계속 쓴다(반쯤 깨진 설정을 절대 반영하지 않음).
- 적용 상태줄(높이 32, 12px):

| 상태 | 표시 |
| --- | --- |
| 적용됨 | `--sim-log-media` 색 "✓ 적용됨 · 11:42:05" |
| 적용 보류 | `--sim-log-dropped` 색 "● 오류 2개 — 마지막 정상 설정 사용 중" (클릭하면 첫 오류로 이동) |
| 경고만 | `--sim-notice-bg` 면 + `--sim-notice-text` "▲ 경고 1개 · 적용됨" |
| 내보내지 않은 변경 | 오른쪽 끝 "내보내기 전" 배지(`--sim-surface-2`, `--sim-text-2`). 펌웨어에 반영하려면 내보내서 커밋해야 하므로 계속 보여준다 |

- 오류(적용 막음): JSON 문법 오류(줄:열), 필수 모드·필드 누락, 알 수 없는 키 이름, 수식키만 있는 조합, 같은 수식키 중복, macOS 칸에 `Win`, `gesture.json` 숫자 범위 밖.
- 경고(적용함): 라벨 5글자 초과(타일 폭), 같은 모드 안 단축키 중복, `cooldownMs` ≠ 800(지시서 기준값).
- 폼에서 오류 칸: 테두리 2px `--sim-log-dropped` + 칸 아래 12px 같은 색 메시지. 색만 쓰지 않고 앞에 "●"(오류) / "▲"(경고) 글자를 붙인다.
- 편집 내용은 브라우저 `localStorage`에 자동 보관(새로고침 대비). 원본은 어디까지나 저장소의 `/shared/*.json`.

### 2.5 JSON 원문 탭

- 고정폭 편집기: `--sim-font-mono` 13px, 줄높이 20px, 왼쪽 줄번호 열 44px(`--sim-text-3`), 면 `--sim-surface-2`. 탭 키 = 공백 2칸.
- 오류 줄: 줄번호 옆 "●" `--sim-log-dropped`, 줄 배경은 바꾸지 않음(가독성).
- 편집기 아래 **오류 목록**(최대 높이 160, 스크롤): `줄 12:7 · 알 수 없는 키 이름 "Ctrll"` 형식. 행 클릭 → 해당 위치로 커서 이동.
- 폼과 원문은 같은 데이터. 원문에 문법 오류가 있으면 폼 탭으로 넘어가지 못하게 하고 "JSON 오류를 먼저 고치세요" 안내.
- 1차 구현은 `<textarea>` + 줄번호면 충분. 문법 강조는 선택 사항(외부 편집기 라이브러리를 쓰면 번들 크기 확인).

### 2.6 내보내기·가져오기

- **내보내기**: `keymap.json` / `gesture.json`을 각각 내려받는다. 들여쓰기 2칸, 키 순서는 스키마 순서 고정, 끝에 줄바꿈 1개 — 커밋 diff가 최소가 되게. 오류가 있으면 내보내기 버튼 비활성 + 툴팁 "오류를 고친 뒤 내보낼 수 있습니다".
- 내보낸 뒤 토스트(패널 아래, 3초): "저장소 /shared/keymap.json 에 덮어쓰고 커밋하면 펌웨어 빌드에 반영됩니다."
- **가져오기**: 파일 선택 또는 패널에 끌어다 놓기(놓는 동안 점선 2px `--sim-focus` 테두리). 먼저 검증 → 확인 대화상자 "변경 12곳 · 오류 0개 — 가져올까요?" [취소][가져오기]. 오류가 있는 파일은 원문 탭에 열어 주되 반영하지 않는다.
- **기본값으로**: 저장소에 들어 있는 버전으로 되돌림. 확인 대화상자 필수.

### 2.7 gesture.json 폼

| 항목(가정 키) | 입력 | 범위·기본 | 설명 줄 |
| --- | --- | --- | --- |
| 튕김 임계값 `flick.thresholdDps` | 슬라이더 + 숫자칸 | 100~1500 °/s, 기본 400 | 그래프 점선과 연동 |
| 시간창 `flick.windowMs` | 슬라이더 + 숫자칸 | 40~300 ms, 기본 150 | 이 시간 안에 임계값을 넘었다 돌아와야 튕김 |
| 재인식 금지 `flick.cooldownMs` | 숫자칸 | 기본 **800** (지시서) | 바꾸면 경고 |
| 판정 축 `flick.axis` | 선택 | roll / pitch / yaw, 기본 roll | |
| 에어마우스 감도 `airMouse.gain` | 숫자칸 3개 | 느림·보통·빠름 | 시계 설정 3단계와 1:1 |
| 데드존 `airMouse.deadzoneDps` | 숫자칸 | 기본 3 | 손떨림 무시 |
| 저역 필터 `airMouse.lowpassHz` | 숫자칸 | 기본 8 | |

슬라이더: 트랙 4px `--sim-border`, 채움 `--sim-focus`, 손잡이 18px. 숫자칸 너비 88, 단위 글자 `--sim-text-3`.

### 2.8 제스처 튜닝 실시간 그래프

gesture.json 폼 위에 붙는다(폼을 스크롤해도 그래프는 패널 상단 고정, 접기 가능).

**크기**: 528×240(패널 560 − 좌우 16). 플롯 영역 x 48~520, y 16~208. 아래 32px에 시간축 글자.

| 요소 | 표현 |
| --- | --- |
| 축 | 가로 = 최근 **5초**(오른쪽이 지금, 왼쪽으로 흐름). 세로 = 각속도 °/s, 범위 ±max(임계값×1.5, 600) 자동 |
| 0선 | 1px `--sim-border` |
| 판정 축 파형 | 2px `--sim-text-1` 실선 |
| 다른 두 축 | 1px `--sim-text-3`, 범례에서 켜고 끔(기본 끔) |
| 임계값 ±선 | 1.5px 점선(6/4) `--sim-log-key`. 오른쪽 끝에 "400°/s" 12px 라벨. **끌어서 값 변경**(잡는 영역 ±6px, 커서 `ns-resize`, 슬라이더와 양방향 연동). 포커스 후 ↑↓ = ±10 |
| 시간창 | 파형이 임계값을 넘는 순간부터 `windowMs` 길이의 괄호(⌐ ¬) `--sim-text-2` 1px |
| 인식 마커 | 채운 삼각형 10px `--sim-log-key` + 라벨 "다음 →"(바깥 튕김, 위쪽 ▲) / "← 이전"(안쪽, 아래쪽 ▼) |
| 쿨다운 구간 | 인식 후 `cooldownMs` 동안 플롯 배경 `--sim-surface-2` 띠 |
| 무시된 후보 | 빈 원 10px `--sim-log-system` + "쿨다운" 또는 "느림"(시간창 초과) 라벨 |
| 읽기값 | 그래프 위 한 줄: "현재 132°/s · 마지막 인식 2.4초 전 · 인식 5 / 무시 3" |

- **입력원 선택**(그래프 위 세그먼트): 마우스 드래그 / 폰 센서 / 녹화 재생(CSV). 재생이면 [재생/일시정지] [0.5× 1× 2×] 진행 막대가 나온다.
- **재판정**: 재생 중 임계값을 바꾸면 같은 녹화를 새 값으로 다시 판정해 "인식 / 무시" 개수를 바로 갱신 — 녹화 데이터로 임계값을 맞추는 지시서 흐름을 그대로 지원.
- [일시정지] 버튼으로 파형 멈춤(멈춘 상태에서도 임계값 끌기 가능). 키보드 Space는 쓰지 않는다(측면 버튼 흉내).
- 그리기: `<canvas>` 60fps, IMU 샘플은 링 버퍼(5초 × 샘플레이트). `prefers-reduced-motion`이면 10fps로 낮춘다.
- 판정 로직은 시뮬레이터 공용 TS 모듈을 그대로 호출(그래프가 판정을 따로 구현하지 않음 — 테스트 벡터와 어긋나지 않게).

## 3. "시계에 설치" 페이지

시뮬레이션 사이트의 별도 경로(예: `/install`). 한 열, 최대 너비 720px, 가운데 정렬, 카드 간격 `--sim-gap` 16. 카드 = `--sim-surface`, 1px `--sim-border`, `--sim-radius-lg`, 안쪽 여백 24.

### 3.1 위 → 아래 순서

| # | 카드 | 내용 |
| --- | --- | --- |
| 0 | 브라우저 확인 띠 | `'serial' in navigator`가 거짓이면 맨 위에 `--sim-notice-bg`/`--sim-notice-text` 띠: "이 페이지는 **데스크톱 Chrome 또는 Edge**에서만 설치할 수 있습니다(Web Serial 필요). Safari·Firefox·모바일은 지원하지 않습니다." 참이면 띠 대신 작은 회색 줄 "Chrome·Edge 확인됨" |
| 1 | 연결 준비 | USB-C 데이터 케이블로 시계를 PC에 연결. 인식이 안 될 때의 방법(BOOT 버튼 등)은 **Waveshare 위키 확인 후** 문구 확정 |
| 2 | 원래 펌웨어 백업 | 설명 + 백업 명령 코드 블록(복사 버튼) + **체크박스** |
| 3 | 버전 선택 | 라디오 목록 |
| 4 | 설치 | ESP Web Tools 버튼 |
| 5 | 원래 펌웨어로 되돌리기 | 접힌 상세(`<details>`) |

### 3.2 백업 확인 체크

- 백업 명령 예(코드 블록, `--sim-font-mono` 13px, `--sim-surface-2`): `python -m esptool --chip esp32s3 --port COM5 read_flash 0 0x1000000 xiaozhi_backup.bin` — 16MB 플래시 기준. 플래시 용량·포트는 실제 보드로 확인 후 확정.
- 체크박스(20px, 행 높이 44, 라벨 14px): "원래 펌웨어(샤오즈)를 백업했습니다. 또는 이미 손목 컨트롤러 펌웨어가 설치되어 있습니다."
- **체크하지 않으면 설치 버튼 비활성.** 페이지를 새로 열 때마다 다시 체크한다(저장하지 않음 — 첫 업로드 전 백업 확인이라는 지시서 규칙을 확실히).

### 3.3 버전 선택

- 라디오 행(높이 56): `v0.3.0` 14px 700 · "최신 · 권장" 배지(`--sim-surface-2`) · 날짜 12px `--sim-text-3` · "변경 내역" 링크(GitHub Release).
- 기본 선택 = 최신. 최신이 아닌 버전을 고르면 행 아래 경고(`--sim-notice-*`): "이전 버전입니다. 설정이 초기화되고 PC와 다시 페어링해야 할 수 있습니다."
- 목록은 CI가 만든 `versions.json`에서 읽는다. **제안**: CI가 `.bin`과 `manifest.json`을 시뮬레이션 사이트의 `/firmware/vX.Y.Z/`에도 복사 — GitHub Release 다운로드 주소는 브라우저 CORS로 막힐 수 있다(파이프라인 담당 확인 필요).

### 3.4 설치 버튼 (ESP Web Tools)

```html
<esp-web-install-button manifest="/firmware/v0.3.0/manifest.json">
  <button slot="activate" class="install-btn" disabled>시계에 설치</button>
  <span slot="unsupported">이 브라우저는 지원하지 않습니다. 데스크톱 Chrome 또는 Edge로 열어 주세요.</span>
  <span slot="not-allowed">보안 연결(https)에서만 설치할 수 있습니다.</span>
</esp-web-install-button>
```

- 버튼: 높이 48, 최소 너비 200, `--sim-radius`, 16px 700, 면 `--sim-mode-coding`. 글자색은 라이트 테마 `--sim-surface`(흰색), 다크 테마 `--wc-text-on-accent`(검정) — 다크의 밝은 파랑 위에서는 검정이 더 잘 읽힌다.
- 상태: 기본 / 눌림(밝기 0.9, 80ms) / **비활성**(면 `--sim-surface-2`, 글자 `--sim-text-3`, 커서 not-allowed — 체크 안 함 또는 지원 안 하는 브라우저) / 포커스(2px `--sim-focus` 링, 2px 띄움).
- 버튼 옆 안내 12px `--sim-text-3`: "설치 중에는 USB를 뽑지 마세요. 약 1분 걸립니다."
- 라디오를 바꾸면 `manifest` 속성을 그 버전 주소로 바꾼다.
- ESP Web Tools 대화상자의 "장치 지우기(Erase)" 선택은 막지 않는다. 다만 버전 행 경고와 같은 내용(설정·페어링 초기화)을 버튼 위에 한 줄 둔다.
- 업로드 버튼을 누르는 것은 **사용자 본인**이다. 개발 중 Claude Code가 이 페이지를 대신 눌러 시계에 올리지 않는다(지시서 규칙).

### 3.5 원래 펌웨어로 되돌리기

`<details>` 접힘, 제목 "원래 펌웨어(샤오즈)로 되돌리기". 펼치면:
1. 백업 파일(`xiaozhi_backup.bin`) 위치 확인
2. 명령: `python -m esptool --chip esp32s3 --port COM5 write_flash 0x0 xiaozhi_backup.bin`
3. "자세한 방법: 저장소 README의 '원래 펌웨어 복원'" 링크
- ESP Web Tools는 로컬 파일을 직접 올리지 못하므로 복원은 esptool 명령으로 안내한다.

## 4. 음성 시뮬레이션 고지

지시서: 음성 시뮬레이션은 사용 흐름 검증용이며 실제 시계 음성 엔진 정확도와 무관함을 **화면에 표시**.

| 위치 | 형태 | 문구 |
| --- | --- | --- |
| ① 시뮬레이터 음성 컨트롤 카드(시계 에뮬레이터 아래, 마이크 버튼 바로 위) | **상시 표시, 닫기 없음.** 띠: `--sim-notice-bg` 면, `--sim-notice-text` 글자 13px, `--sim-radius`, 안쪽 여백 8×12, 왼쪽 `i-voice` 16px. 최소 높이 40 | "음성 시뮬레이션은 브라우저 음성 인식을 씁니다. 흐름 확인용이며, 실제 시계 음성 인식 정확도와는 관계없습니다." |
| ② 마이크 권한을 처음 요청하기 직전 | 확인 대화상자 본문 첫 줄 | ①과 같은 문장 + "[계속] [취소]" |
| ③ HID 로그 | 음성으로 생긴 이벤트 앞에 태그 `음성·브라우저` (`--sim-log-system`) | |
| ④ Web Speech 미지원(Firefox 등) | ① 자리에 같은 띠로 | "이 브라우저는 음성 인식을 지원하지 않아 음성 시뮬레이션을 쓸 수 없습니다. Chrome·Edge에서 열어 주세요." |

- 시계 에뮬레이터 **화면 안**(`.wc-screen`)에는 고지를 넣지 않는다 — 실제 시계 화면과 달라지면 화면 검증 의미가 흐려진다. 고지는 베젤 바깥 시뮬레이터 UI에만.
- "키트, 다음" 넘김 / "다음" 단독 무시 판정 결과는 HID 로그에 각각 "넘김" / "무시(호출어 없음)"로 남긴다.

1. **시트 담당(1번)**: 아래 스와이프 시트에 설정 행 추가 → 시트 높이 240 → 344.
