3. "시계에 설치" 페이지

이 페이지는 데스크톱 Chrome 또는 Edge에서만 설치할 수 있습니다(Web Serial 필요). Safari·Firefox·모바일은 지원하지 않습니다.

1시계 연결

USB-C 데이터 케이블로 시계를 PC에 연결합니다. 인식이 안 될 때의 방법은 Waveshare 위키 확인 후 문구를 확정합니다.

2원래 펌웨어 백업

처음 설치라면 지금 시계에 있는 펌웨어(샤오즈)를 먼저 통째로 백업하세요. 되돌릴 수 있는 유일한 방법입니다.

python -m esptool --chip esp32s3 --port COM5 read_flash 0 0x1000000 xiaozhi_backup.bin

3버전 선택

이전 버전입니다. 설정이 초기화되고 PC와 다시 페어링해야 할 수 있습니다.

4설치

설치 창에서 "장치 지우기"를 고르면 설정과 페어링 정보도 지워집니다.

백업 확인을 체크하면 설치할 수 있습니다.

설치 중에는 USB를 뽑지 마세요. 약 1분 걸립니다. manifest: /firmware/v0.3.0/manifest.json

원래 펌웨어(샤오즈)로 되돌리기
  1. 백업 파일 xiaozhi_backup.bin 위치를 확인합니다.
  2. 아래 명령으로 다시 씁니다. (이 페이지는 로컬 파일을 직접 올리지 못합니다)
python -m esptool --chip esp32s3 --port COM5 write_flash 0x0 xiaozhi_backup.bin

자세한 방법: 저장소 README의 "원래 펌웨어 복원"

4. 음성 시뮬레이션 고지 위치

시뮬레이터 왼쪽 열, 시계 에뮬레이터 바로 아래 "음성" 카드. 마이크 버튼 위에 상시 표시하며 닫을 수 없다. 시계 화면(.wc-screen) 안에는 넣지 않는다.
