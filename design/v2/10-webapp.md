# v2 웹앱(시뮬레이터 PWA) 고도화

2026-10-17 · v2 디자이너 10번 · 기준: `simulator-layout.md`, `settings-install.md`, `docs/research/launcher.md`, `sim/src/*`(shell/toolbar.ts, pwa.ts, install/install.ts), `shared/keymap.json`

대상: **폰으로 먼저 여는 교사**. 데스크톱 3단 배치(simulator-layout.md 2.1)는 폭 1024 이상에서 그대로 두고, 이 문서는 **폭 767 이하(폰 세로)** 를 기준 화면으로 다시 그린다. 기준 기기 폭: **360**(소형)·**390**(일반)·**430**(대형). 좌표는 CSS px이며 달리 적지 않으면 W=390이다.
색은 `--sim-*`, 시계 화면 안쪽은 `--wc-*`만 쓴다(새 토큰 없음). 모드색: 시계 = `--sim-text-2`(회색), 발표 = `--sim-mode-present`, 실행 = `--sim-mode-coding`(파랑 재사용), 회의 = `--sim-mode-meeting`. 모드 순서는 `keymap.modeOrder` = clock · present · launch · meeting.

## 1. 폰 세로 레이아웃 (기준 화면)

### 1.1 영역 (W=390, H=844 예시. 노치·홈바는 `env(safe-area-inset-*)` 추가)

```
y   0 +- 상단 바 52 ---- ● 손목 컨트롤러      [연결됨]  [⋯] -+
y  52 +- (첫 방문만) 첫 화면 카드 --- 2장 ----------------------+
      +- 시계 영역: 폭 358 안에서 s=0.716 -> 기기 358x388 ------+
      |   베젤 450x542 -> 322x388, 화면 410x502 -> 294x359      |
      +- 모드 줄 40:  [‹]  ● 현재 모드 칩  [›]    캡션 72%       -+
      +- 탭 바 48:  PC 화면 | 기록 | 실행 설정 -------------------+
      |  탭 본문 (최소 높이 360)                                  |
y 788 +- 하단 고정 바 56 + 홈바: 측면 버튼 2개 ------------------+
```

- 좌우 여백 **16**, 영역 간격 **12**. 시계 열 폭 = `W − 32`. 축척 `s = min(1, (W−32)/500)`: W=360 → 0.656(기기 328×356), 390 → 0.716(358×388), 430 → 0.796(398×431). 계산은 `innerWidth`가 아니라 **시계 열의 실제 폭**(simulator-layout.md 2.1과 같음).
- 소형 폰 높이 합: 상단 52 + 시계 356 + 모드 줄 40 + 탭 바 48 = 496, 가용 640 이내라 시계는 항상 한 화면에 전부 보인다. 탭 본문이 모자라면 페이지가 스크롤된다(시계 sticky 안 함 — 본문이 너무 좁아지기 때문).
- 가로(landscape) 폰(높이 < 480): 시계 s=0.55를 왼쪽에, 오른쪽에 탭 본문(`grid-template-columns: auto 1fr`). 태블릿(768–1023)은 simulator-layout.md 그대로.

### 1.2 상단 바 (52, 폰)

| 요소 | 좌표 (x, y, w, h) | 내용 |
| --- | --- | --- |
| 브랜드 | 16, 0, 가변, 52 | 점 10(현재 모드색, 200ms) + "손목 컨트롤러" 16/700. "시뮬레이터" 보조 글자는 폰에서 숨김 |
| 연결 알약 | 우측, 터치 44, 보이는 높이 32, 폭 ≈ 96 | 연결: 점 8 `--sim-log-media` + "연결됨". 끊김: `--sim-log-dropped` + "끊김". 누르면 끊김/연결 흉내(지금의 `BLE 연결됨` 버튼을 알약으로 승격). 글자 병기 |
| 더보기 ⋯ | 우측 끝, 44×44 | 바닥 시트: 손목 입력 방식, 테마(자동/라이트/다크), 앱으로 설치, 시계 설치, 시간 맞추기, 도움말, 버전. **툴바의 테마·설정·설치 링크가 모두 이쪽으로** |

- 상단 바는 sticky 해제(폰). 손목 입력 세그먼트는 상단 바에서 빼서 시계 바로 아래 손목 움직임 줄(3.2)로 내린다. 음성 버튼은 없다.

## 2. 첫 화면

원칙: ① 첫 줄에서 **이게 뭔지** 알려준다. ② BLE·HID·IMU 같은 단어를 쓰지 않는다. ③ 누를 것이 한눈에 보인다. ④ 한 번 해 보면 접어서 공간을 돌려준다.

### 2.1 연습 카드 (첫 방문일 때만)

위치 x16, y60, 358×(가변 ≈ 252). `--sim-surface`, 1px `--sim-border`, 반경 16, 안쪽 16.

```
+--------------------------------------+
| 손목 컨트롤러 체험              [접기 ˅]|  16/700, 접기 44x44
| 시계를 손목에 차고 PC 화면을              |  14/1.5 --sim-text-2
| 넘기는 연습을 여기서 먼저 해 봅니다.        |  (2줄)
|                                      |
| ① 시계 화면 오른쪽을 눌러 보세요 [해보기]  |  행 높이 56, 번호 원 24
| ② 좌우로 쓸어 모드를 바꿔 보세요 [해보기]  |
| ③ 가운데를 길게 눌러 화면을 끄세요 [해보기] |  (발표 모드로 자동 전환)
|                                      |
| 진짜 시계에 넣으려면 → 시계에 설치         |  14/600 --sim-focus
+--------------------------------------+
```

- [해보기]는 시계 에뮬레이터를 실제로 조작하게 안내한다: ① 발표 모드로 두고 오른쪽 영역에 1.2초 펄스 링(3px `--sim-mode-present`, 지름 88), ② 모드 슬라이드 화살표 힌트 2회, ③ 중앙에 600ms 진행 링. 링은 **시계 화면 바깥(베젤 위 오버레이)** 에 그려 화면 검증을 흐리지 않는다.
- 행 완료는 실제 입력이 일어나면 감지: 번호 원 → "✓"(`--sim-log-media`), 글자 `--sim-text-3`. 3개가 끝나면 카드가 200ms에 **한 줄 막대(44)** 로 접히고 "연습 완료 · 다시 보기"만 남는다. 저장: `wrist-sim.onboard.v1`(try/catch, 없어도 렌더됨).
- 높이 합 52 + 252 + 388 = 692라 소형 폰에서는 시계가 반쯤 가려진다. 기본은 **접힘 막대 + 첫 행만(높이 128)** 으로 시작하고 펼치면 전체. 연습이 필요한 첫 방문에서만 펼침.
- 이 카드에 음성 문구 없음. 연결·끊김 설명도 넣지 않는다(알약이 말해 줌).

### 2.2 첫 화면의 시계·PC 상태

- 시작 모드 `clock`. 시계 화면 안에 사이트 요소(손가락 힌트 등)는 넣지 않는다. 베젤 아래 12px 캡션 "화면을 눌러 보세요".
- PC 탭이 기본, **발표 모드의 슬라이드 편집 보기**로 시작(①을 누르면 바로 슬라이드가 넘어가는 반응이 보임, `pc/slides.ts`).

### 3.2 손목 움직임 (시계 바로 아래, 접이식 한 줄 48)

- 접힌 상태: "손목 입력: 폰 기울이기 ˅". 펼치면 simulator-layout.md 4.4의 패드/센서/재생(높이 160).
- **기본값**: 폰 = `폰 기울이기`(iOS는 첫 누름에 권한 요청, 버튼 "센서 켜기" 56. 거부하면 `드래그`로 되돌리고 안내 한 줄), 데스크톱 = `마우스 드래그`.
- 세그먼트 폭 `(358−4)/3 ≈ 118`, 높이 44. 라벨 `드래그` / `폰 기울이기` / `녹화 재생`. 선택 = 면 + 그림자 + 600.

### 3.3 하단 고정 바 — 측면 버튼 (폰 전용, 높이 56 + 홈바)

`--sim-surface` 면, 위 1px `--sim-border`. 버튼 2개 폭 `(358−12)/2 = 173`, 높이 44, 반경 `--sim-radius`:

| 버튼 | 라벨 | 동작 |
| --- | --- | --- |
| 왼쪽 | `화면 켜기/끄기` | PWR 짧게 |
| 오른쪽 | `주 버튼` | BOOT. 누른 채 손목 = 에어마우스. 2초 = 잠금. 누르는 동안 위 3px 막대 `--wc-locked`가 2000ms 선형으로 참 |

본문 `padding-bottom: 56 + inset`. 입력칸 포커스로 키보드가 올라오면 바 숨김.

## 4. 가상 PC · HID 로그 (폰 세로, 탭 전환)

### 4.1 탭 바 (높이 48)

탭 3개 균등 폭 118, 글자 14. 선택 = 700 + 아래 3px `--sim-focus` 밑줄(폭 36, 가운데). 터치 높이 48. 스크롤하면 화면 위에 붙는다(`position: sticky; top: 0`).

| 탭 | 내용 | 뱃지 |
| --- | --- | --- |
| `PC 화면` (기본) | 4.2 | 끊김이면 점 8 `--sim-log-dropped` |
| `기록` | 4.3 | 안 본 새 기록 수(`99+` 상한), 알약 높이 18. PC 탭을 보는 중에도 쌓임 |
| `실행 설정` | 5장 | 저장 안 된 변경 점 8 `--sim-notice-text` |

- 탭 전환은 즉시(0ms). 마지막 탭은 `localStorage`로 기억(실패 무시).
- **조작 직후 피드백**: 다른 탭을 보고 있어도 키가 나가면 시계 모드 줄 오른쪽에 키캡("→ Right")이 1200ms 뜬다(`pc.ts`의 마지막 입력 키캡 재사용). 그래서 시계를 누르며 탭을 오갈 필요가 없다.

### 4.2 PC 화면 탭

| 요소 | 좌표 (본문 폭 358) | 규칙 |
| --- | --- | --- |
| 앱 라벨 칩 | 16, 0, 358×28 | "슬라이드 쇼 · 3/10", "작업표시줄 · Claude 실행", "회의 창 · 마이크 꺼짐" |

| 하단 줄 | 높이 40 | `마지막 입력` [키캡] · `Windows`. 커서 좌표는 숨김(길게 누르면 툴팁) |

**모드별 가상 PC**: 시계 = 바탕화면 + 시각만(캡션 "시계 모드: PC로 보내는 입력 없음"), 발표 = 슬라이드 편집/쇼/암전(simulator-layout.md 5.2), 회의 = 회의 창(5.5), **실행 = 가상 바탕화면 + 작업표시줄(신규)**.

**실행 모드 가상 PC**: 화면 하단에 작업표시줄 높이 28, 칸 6개(폭 40)에 글자 두 자(클/카/크/파/엑/한) + 번호 1~6(8px 위첨자). 타일을 눌러 **Win+N**이 가면 N번 칸이 1.2초 강조(2px `--sim-mode-coding`)되고 해당 앱 이름이 제목줄에 보이는 창 모형이 뜬다. 5장에서 작업표시줄 번호를 바꾸면 칸 순서가 바뀌어 "내 PC 작업표시줄과 같은지"를 눈으로 맞춘다. 상표 로고·고유색 금지(simulator-layout.md 5.1).

## 5. 실행 모드 설정 편집 — 타일별 실행 방식 (핵심 UX)

```
 [ 설정 파일 받기 ]  [ 시계에 보내기(곧 지원) ]  [ 처음으로 ]  [ 고급: JSON ]
```

- 카드 배치·번호는 시계 타일과 같은 순서(시계는 2×3, 폰 폭에서는 3×2로 그려도 번호·라벨이 같다). 카드 터치 114×96 ≥ 88.
- 카드 상태: 기본(`--sim-surface` + 1px) / 편집 중(시트 열림, 2px `--sim-focus`) / 사용 안 함(면 `--sim-surface-2` + 점선 + 요약 "사용 안 함") / 오류(요약 앞 `●` 빨강 + "주소를 넣어 주세요").
- 요약 예: `Win+1` · `실행창: powerpnt` · `주소 열기` · `사용 안 함`. 길면 말줄임.
- 순서 바꾸기: 카드 길게 누르면 `‹ ›` 이동 버튼 두 개가 나타남(폰은 드래그가 스크롤과 충돌). `actions` 배열 순서가 바뀌고 시계가 바로 갱신.
- 상단 안내(12px): "타일을 누르면 어떻게 실행할지 고릅니다. 바꾼 즉시 위의 시계에 반영됩니다."

### 5.2 타일 편집 시트

폰: 바닥 시트 높이 `min(86vh, 640)`, 상단 반경 16, 손잡이 36×4, 덮개 `rgba(0,0,0,.4)`, 올라오기 `translateY` 200ms. 데스크톱: 오른쪽 서랍 420. `Esc`·덮개 탭·아래로 쓸기·`완료` = 닫기. **변경은 입력 즉시 시계에 반영**(검증 통과 시). `완료`는 저장이 아니라 닫기.

```
 ━━                                 손잡이
 (3) 크롬  [______]     4/5          제목 줄 56: 번호 원 28, 이름 입력 18/700
 -- 누르면 ---------------------------
 (●) 작업표시줄 3번 앱 열기   Win+3    기본 · 권장 배지
 ( ) 실행창으로 열기  이름 [chrome___]
 ( ) 웹 주소 열기    주소 [https://___]
 ( ) 단축키 보내기   [키를 누르세요]
 ( ) 사용 안 함
 -- 길게 누르면 (백업 방식) -------------
 ( ) 안 함  ( ) 실행창으로 열기  ( ) 직접 고르기
 -- Mac에서 쓸 때 (접힘) ---------------
 Spotlight 이름 [Google Chrome]
 -- 시험 ----------------------------
 [ 가상 PC에서 눌러보기 ]   ✓ Win+3 보냄 · 총 0.1초
 [ 이 타일 처음 설정으로 ]            [ 완료 ]
```

**실행 방식 5가지** (라디오, 행 높이 56, 행 전체가 터치 대상)

| 한국어 라벨 | 저장 형식 (`win`) | 입력칸 | 설명 줄(12px) | 주의 |
| --- | --- | --- | --- | --- |
| 작업표시줄 N번 앱 열기 **(기본)** | `{mods:[gui], key:"N"}` | N 선택 `1`~`9`,`0`. 기본값 = 타일 칸 번호 | "작업표시줄에 고정한 N번째 앱을 엽니다. 한/영 상태와 무관해 가장 안정적입니다." | 앞에 떠 있는 앱이면 최소화될 수 있음(launcher.md 2.1, 실기 확인) |
| 실행창으로 열기 | steps: Win+R → wait 300 → text `{이름}` → wait 50 → ENTER | 영문·숫자·`.`·`-`, 1~96자. **한글은 즉시 오류** | "실행창에 영문 이름을 입력합니다. 한글 입력 상태면 실패할 수 있어요." | `한/영` 노랑 띠 |
| 웹 주소 열기 | Win+R → wait 300 → text `{url}` → ENTER | 주소 `https://…`(최대 96자), `url` 필드 | "기본 브라우저로 엽니다. 로그인은 자동으로 하지 않습니다." | `https://`가 아니면 오류 |
| 단축키 보내기 | `{mods, key}` | 키 캡처 입력칸(settings-install.md 2.3 재사용) | "예: Win+Shift+S" | 수식키만 있으면 오류 |
| 사용 안 함 | `null` | — | "시계에서 회색으로 보이고 눌러도 아무 일도 없습니다." | — |

- 실행창·웹 주소를 고르면 시트 위 노랑 띠(`--sim-notice-*`): "글자를 한 자씩 입력합니다. 시작 전에 PC 입력 상태를 영문(A)으로 맞춰 주세요."
- 2쪽 업무포털은 `웹 주소 열기`로 시작하되 주소가 비면 비활성 + "주소를 넣어 주세요"(`url` 비어 있으면 비활성 규칙). 주소를 넣으면 즉시 활성.
- 길게 누르기(`winAlt`) = "백업 실행 방식". 기본은 `안 함`. launcher.md 2.3의 Win+R 대안을 `실행창으로 열기`로 제안만 하고 자동 적용하지 않는다.
- Mac 영역: 기본 접힘, 필드는 Spotlight 영문 이름 하나(`Cmd+Space → 300 → 이름 → 300 → Return`). 한글 입력 오류 동일.
- **가상 PC에서 눌러보기**: 시계 에뮬레이터에 타일 누름을 주입(실제 입력과 같은 경로)하고, 시트 아래 결과 줄에 "✓ Win+3 보냄 · 총 0.1초". 매크로는 "Win+R → 0.3초 대기 → 글자 7개 → 0.05초 대기 → Enter"로 한 줄 요약.

### 5.3 검증·메시지

- 입력 멈춤 300ms 뒤 `validate.ts` 규칙 재사용. **오류가 있으면 시계에 반영하지 않고** 마지막 정상 설정 유지. 상태줄(32): `✓ 적용됨 11:42` / `● 오류 1개 — 마지막 정상 설정 사용 중` / `▲ 경고 1개 · 적용됨`. 색과 ●/▲ 글자를 함께.
- 오류 예: "이름에 한글을 쓸 수 없습니다", "주소는 https://로 시작해야 합니다", "단계가 24개를 넘습니다". 경고 예: "▲ 3번 칸과 같은 키입니다", "▲ 라벨이 5글자를 넘어 타일에서 잘립니다".

### 5.4 저장·시계에 보내기 (약속을 정직하게)

지금 펌웨어는 키맵을 **빌드에 포함**한다(`tools/`가 C 헤더 생성). 웹앱이 시계 설정을 즉시 바꾸지는 못한다.

| 단계 | 버튼 | 하는 일 | 지금 가능? |
| --- | --- | --- | --- |
| ① 이 브라우저에 저장 | (자동) | `localStorage` 보관, 배지 "이 폰에만 저장됨" | 가능 |
| ② 파일로 내보내기 | `설정 파일 받기` | `keymap.json` 다운로드. 폰은 `navigator.share({files})` 우선(카카오톡·메일로 PC에 보내기) | 가능 |
| ③ 시계에 적용 | `시계에 보내기` | v2 제안: 시계에 키맵 저장 영역(NVS/LittleFS)을 두고 설치 페이지와 같은 연결로 올림 | 펌웨어 합의 필요. 전까지 "곧 지원" 비활성 + 툴팁 |

- 비활성 버튼 옆 한 줄: "지금은 설정을 파일로 저장해 두었다가, 시계를 다시 설치할 때 함께 적용돼요."
- `고급: JSON`은 기존 `settingsPanel.ts` 원문 편집을 연다(폰 = 전체 화면 시트).

### 6.1 구조 (한 열, 최대 720, 폰 16 여백)

| # | 카드 | 폰 | 데스크톱 |
| --- | --- | --- | --- |
| 0 | **스텝퍼** (높이 56) | ① 준비 ② 백업 ③ 설치 ④ 시간 맞추기. 원 28 + 라벨 12. 현재 = `--sim-focus`, 완료 ✓ `--sim-log-media`. ③은 ② 체크 전 비활성 | 가로 360 |

### 6.3 시간 맞추기 (설치 직후, 또는 언제든)

시계 모드가 첫 화면이라 시각이 틀리면 바로 눈에 띈다. 보내는 방법은 3가지, **기기에서 되는 것을 위에서부터 자동 선택**한다.

| 순위 | 방법 | 환경 | 버튼 문구 | 필요한 것 |
| --- | --- | --- | --- | --- |
| A | Web Bluetooth | 안드로이드 Chrome(폰) | `시계에 지금 시간 보내기` → 기기 선택 → ✓ | 펌웨어가 표준 Current Time(0x1805/0x2A2B, 10바이트) 또는 전용 특성 1개를 노출. HID 연결 중 별도 GATT 접속 가능 여부 **미확인(실기)** |
| B | Web Serial (USB) | 데스크톱 Chrome/Edge | 설치 직후 "시간도 맞출까요? [맞추기]" | 시리얼 명령 `TIME <epoch초> <UTC오프셋분>` |
| C | 손으로 맞추기 | 모든 환경(폴백) | `손으로 맞추기 보기` | 시계 설정 화면에 시각 항목(설정 화면 담당과 합의). 웹앱은 안내 그림만 |

```
+ ④ 시간 맞추기 ----------------------------+
 지금 이 기기의 시각       24/700 tabular, 1초 갱신
 2026-10-17 (토) 오후 3:42:18
 시간대: 한국 표준시 (UTC+9)   [바꾸기]
 [ 시계에 지금 시간 보내기 ]     높이 56 폭 100%
 보낸 뒤 시계의 시각이 위와 같은지 확인하세요.
 ✓ 맞췄어요 · 3:42:19
+-----------------------------------------+
```

- 상태: `대기` / `찾는 중…`(최대 10초, 점 3개 1000ms 순환 — reduced-motion이면 정지 글자) / `✓ 맞춤` / `● 실패`(이유 한 줄: "시계를 찾지 못했어요 · 시계를 깨우고 1m 안에서 다시").
- 보정: 전송 직전 `Date.now()`에 write 왕복 지연/2를 더한다. 목표 오차 ±1초(교실 용도, 시계는 hh:mm 표시).
- **자동 제안**: 설치 완료 직후 1회(B), 더보기 시트에 상시 버튼. 시계가 시각을 광고하게 되면 "5분 이상 다릅니다" 제안(A).
- Web Bluetooth가 없으면 A를 숨기고 B 또는 C. 시간대 기본 = `Intl.DateTimeFormat().resolvedOptions().timeZone`.
- 로그 연계: SYS `시간 맞춤 요청 15:42:18 (UTC+9)`.

## 7. 앱 설치 안내 (PWA)

목적: 교실에서 **인터넷 없이도 시뮬레이터를 열게** 홈 화면에 올리도록 안내(현재 `pwa.ts`는 서비스워커만 등록).

### 7.1 노출 규칙

- 이미 설치됨(`display-mode: standalone` / `navigator.standalone`)이면 아무것도 안 보임. 아니면 **연습 카드 완료 직후 또는 방문 2회째** 1회 표시. 닫으면 14일 숨김(`wrist-sim.pwainstall.v1`, try/catch). 더보기 시트에는 항상 "앱으로 설치" 행.
- 위치: 폰은 화면 아래 안내 시트(높이 약 220, 폭 358, z 9999). 서비스워커 "새 버전" 바(하단 16)와 겹치지 않게 그 위 68에 쌓는다.

### 7.2 환경별 문구 (한 시트에 1개만)

| 환경 | 판별 | 내용 | 동작 |
| --- | --- | --- | --- |
| Android Chrome·삼성 인터넷 | `beforeinstallprompt` 수신 | "홈 화면에 앱으로 넣어 두면 수업 중 바로 열 수 있어요." `[앱 설치]` 56 / `[나중에]` | `prompt()`. 거절 시 14일 숨김 |
| iPhone·iPad Safari | iOS + Safari + 미설치 | 3단계 목록(번호 원 24): ① 아래 **공유** 누르기 ② **홈 화면에 추가** ③ **추가** | 프로그램 설치 불가 → 안내만 |
| iOS 다른 브라우저 | iOS + `CriOS` 등 | "iPhone에서는 **Safari**에서 열어야 설치할 수 있어요." `링크 복사` | — |
| 데스크톱 Chrome·Edge | `beforeinstallprompt` | "주소창 오른쪽 설치 아이콘으로 PC 앱으로 설치할 수 있어요." `[앱 설치]` | `prompt()` |
| 그 밖(Firefox 등) | 위 모두 아님 | 시트 없음. 더보기 행은 "이 브라우저는 지원하지 않습니다"로 흐리게 | — |

- 공통: 폭 358, 반경 16, 면 `--sim-surface`, 위 1px `--sim-border`, 안쪽 16, 글자 14/1.5, 버튼 56. 등장 200ms `translateY`(reduced-motion이면 즉시).
- 매니페스트: `name` "손목 컨트롤러", `short_name` "손목컨트롤러"(유지), `display: standalone`, `theme_color #000000`. **`orientation: portrait` 추가 제안**. `shortcuts` 2개 제안: `연습하기`(`./?onboard=1`), `시계 설치`(`./install.html`).
- 오프라인(`navigator.onLine === false`): 상단 바 아래 24px 회색 띠 "오프라인 · 시계 설치 페이지는 인터넷이 필요합니다"(ESP Web Tools를 unpkg에서 받음). 시뮬레이터 본체는 정상.
- `pwa.ts` 상단 주석의 "음성 인식(Chrome)은 인터넷 필요" 문구는 삭제.

## 10. 접근성·성능

- 모든 터치 대상 **44×44 이상**(시계 화면 안은 88). 라디오·카드 행은 행 전체가 대상.
- 포커스 링 2px `--sim-focus`(간격 2). 시트·덮개는 포커스 트랩, `Esc` 닫기, 닫으면 호출 요소로 포커스 복귀.
- 색만으로 구분하지 않는다: ● ▲ ✓ 글자 병기, 모드 칩은 색 점 + 이름.
- `prefers-reduced-motion`: 시트·점 순환·펄스 모두 0ms 또는 정지 글자.
- 글자 최소 12(보조), 본문 14, 라벨 14–16. `meta viewport`에서 확대를 막지 않는다.
- 새 라이브러리 없음(CSS + 기존 모듈 확장). QR·드래그 정렬 라이브러리 쓰지 않음.

## 11. 구현 순서

1. 음성 제거(8장) + 폰 레이아웃 + 탭 바(1·4장). 2. 연습 카드(2장). 3. 실행 설정 목록·시트(5장, `settingsPanel.ts`에 launch 전용 폼). 4. PWA 설치 안내(7장). 5. 설치 페이지 스텝퍼·PC에서 열기(6.1–6.2). 6. 시간 맞추기(6.3, 펌웨어 합의 후).

## 12. 다른 담당과 합의할 것

- **펌웨어**: (a) 시각 설정 경로(Current Time 특성 또는 시리얼 `TIME` 명령) + 시계 설정 화면의 수동 시각 입력, (b) 키맵을 런타임에 교체할 저장 영역(5.4 ③), (c) HID 연결 중 별도 GATT 접속 허용 여부.
- **시계 설정 화면 담당**: 시각 항목 추가, 이름 후보에 한글 이름 포함 여부.
- **스키마**: `voiceEnabled` 삭제, 매크로 `{이름}` 입력 제약(영문·숫자·`. -`, 1~96자), `url` 규칙.
- **디자인 1번(시스템)**: 필요하면 아이콘 `i-share`·`i-tile` 추가, 없으면 글자 라벨.
