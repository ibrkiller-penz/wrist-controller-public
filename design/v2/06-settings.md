## 1. 설정 화면 — 목록

### 1.1 진입·종료 (변경 없음 + 보강)
- 진입: 위에서 당겨 내린 시트 맨 아래 "설정" 행(88px) 탭. 오른쪽에서 **200ms** 슬라이드(`--wc-motion-base`; 280ms보다 줄임: 40줄 버퍼라 전체 화면 이동은 13조각으로 나눠 그리므로 프레임이 적을수록 덜 끊김. 느리면 즉시 표시로 대체 가능).
- 종료: ①맨 아래 "닫기" ②오른쪽 스와이프(가로 80↑·세로 60↓) ③측면 버튼 짧게 ④30초 무입력. 설정 중에는 **HID 키를 보내지 않는다**(측면 누른 채 이동 = 에어마우스만 허용, 감도 시험용).
- 상태줄(y 0~56)은 그대로 두고 모드 이름 자리에 **"설정"**(label 22, 이전 모드색 `--wc-accent`) + 기어 아이콘. 그래서 목록 제목 줄이 필요 없고 목록이 y 64부터 시작한다.

### 1.5 스크롤

- 위젯: 목록 컨테이너 `lv_obj` 하나(x 0, y 56, 410×446), 자식 행은 `lv_obj`. `LV_DIR_VER`만, `LV_OBJ_FLAG_SCROLL_MOMENTUM` 켬, `SCROLL_ELASTIC` **끔**(되튕김은 추가 프레임), `SCROLL_CHAIN` 끔.
- 스크롤 시작 임계 `lv_indev_set_scroll_limit(indev, 12)`, 관성 `scroll_throw` 6(기본 10보다 짧게 — 손목에서 과하게 미끄러지지 않게).
- 스크롤바: `LV_SCROLLBAR_MODE_ACTIVE`, 폭 4, x 400(오른쪽 곡률 안쪽), 색 `--wc-text-3`, 반경 pill, 트랙 없음.
- 진입할 때마다 스크롤 0으로 시작(`lv_obj_scroll_to_y(.., 0, LV_ANIM_OFF)`).
- 스크롤 중 비용: 행에 그림자·그라데이션·알파가 없어 단순 사각형·글자만 다시 그림. 한 프레임 약 25~35ms 예상(약 20~30fps, 실측 필요). 스크롤 중 스위치 애니메이션은 끈다.

## 7. 한글 글꼴 서브셋과 플래시 비용

이 문서 화면에서 쓰는 한글 글자: 설정, 에어마우스, 감도, 느림, 보통, 빠름, 컴퓨터, 보내는, 단축키, 종류, 손목, 들면, 시계, 부터, 보임, 들어, 올리면, 켬, 끔, 움직임, 기록, 녹화, 배터리, 더, 씀, 자동, 종료, 시작, 블루투스, 이름, 선택, 정보, 버전, 닫기, 취소, 바꾸기, 바꿀까요, 연결, 대기, 끊김, 찾는, 중, 초, 분, 넘음, 확인, 컨트롤러, 수업, 리모컨, 다시, 멈췄습니다, 안, 보이면, 목록, 이전, 기기, 삭제, 찾으세요, 누르세요, 하는, 됨, 끝, 글자, 시계만의, 값, 구분, 합니다, 끊기고, 제스처, 잠김, 풀림, 부족, 실패, 전송, 변경, 추가, 및, 위, 적용. **고유 한글 약 95자**(추정; 확정은 `lv_font_conv --symbols` 목록을 만들 때).

LVGL 변환기(bpp 4, 압축 켬) 기준 글자당 플래시 **추정치**(한글은 영문의 2~3배 획; 실제는 변환 결과 `.c` 크기로 확인):

| 크기 | 쓰는 곳 | 글자 수 | 글자당 ≈ | 합계 ≈ |
| --- | --- | --- | --- | --- |
| 20px | 힌트·안내(caption) | ~55 | 150B | 8KB |
| 22px | 보조줄·상태줄(label) | ~95 | 180B | 17KB |
| 26px | 행 제목·토스트·버튼(body) | ~70 | 250B | 18KB |
| 32px | 확인 카드 제목(heading) | ~8 | 380B | 3KB |
| 40px | 페어링 이름(title) | 11 (`손목 컨트롤러`, `수업 리모컨`) | 600B | 7KB |
| 합계 | | | | **약 53KB** (+ 글자표·메타 약 6KB) |

- 비교: KS X 1001 완성형 2,350자 전부 26px 는 약 590KB. 16MB 플래시에는 들어가지만 **필요한 글자만**으로 충분. 다른 화면(발표·실행·회의) 글자를 합쳐도 100~150KB 예상.
- RAM: 서브셋 폰트는 `const` 로 플래시에 있어 RAM 을 안 쓴다. 객체 RAM 추정: 설정 약 30개 × 150~250B ≈ 6KB, 이름 선택 ≈ 3KB, 확인 카드 ≈ 2KB, 페어링 ≈ 2.5KB, 토스트·배너 ≈ 2KB → **합계 약 16KB**(내부 RAM 여유 ~140KB 중). 전부 부팅 때 한 번 만들고 `LV_OBJ_FLAG_HIDDEN` 으로 숨긴다(숨긴 객체는 그리지 않음).
- 영문·숫자(`D7C2`, `Windows`, `v0.1.0`)는 Montserrat(20/22→26/48)에 있음. 한 줄에 한글과 섞이는 곳(`손목 컨트롤러 D7C2` 미리보기 줄)은 한글 폰트에 ASCII 를 포함해 높이를 맞춘다. Montserrat 48 은 끝자리 칩 전용.
