# v2-01 시계 모드(기본 화면) 디자인

담당: 디자이너 1번. 대상: `clock` 모드 한 화면(410×502, 순검정). 음성 기능은 없다.
좌표는 모두 **화면 좌표(px), 원점 좌상단**. "ink" = 글자가 실제로 칠해지는 높이(숫자 높이).
기준 코드: `firmware/main/ui.cpp` buildClock(), `sim/src/watch/screens.ts` ClockView.

---

## 0. 현재 문제 (캡처·코드에서 확인)

| 문제 | 현재 | 영향 |
|---|---|---|
| 시:분이 작다 | Montserrat 48 (숫자 ink 약 35px, 폭 약 150px) | 410px 폭의 37%만 씀. 팔을 뻗어 보는 시계의 핵심 정보가 가장 약함 |
| 시각이 두 번 나옴 | 상태줄 sbClock(20px) + 큰 시계 | 중복. 시계 모드에선 상태줄 시각이 필요 없음 |
| 날짜가 영문 | 영문 요일·월 | 한국 교사 대상인데 한글이 아님 |
| 초 점이 정적 | kSec 12px 원이 늘 같은 자리 | 번인 위험, 정보 가치 없음 |
| 번인 대책 없음 | 모든 요소 고정 좌표, 밝기 고정 | AMOLED 상시 사용 시 숫자 윤곽이 남음 |
| 안내문이 상시 | "no keys sent - swipe..." 14px 고정 | 정적 요소, 영문, 14px(최소 20 위반) |
| 모드 색 없음 | `--wc-mode-clock` 가 tokens.css 에 **정의돼 있지 않음**(참조만 있음, 177~180줄) | 상태줄 시계 모드 색이 깨짐 → 3절에서 정의 |

세로 균형: 정보 블록(숫자 ink 92 + 간격 32 + 날짜 ink 약 28) 높이 약 152, 블록 중심 y 약 252. 상태줄 아래 영역의 중심(279)보다 일부러 약 27px 위에 둔다(손목을 들어 비스듬히 볼 때 시선이 위쪽, 하단은 끊김 배너 자리).

### 2.3 날짜·요일 표기

- 형식: `10월 17일` + 요일 한 글자 칩 `[토]`. 연도는 넣지 않는다(손목에서는 불필요).
- 요일 칩(알약 52×40, 반경 20, 테두리 2px, 배경 투명):

| 요일 | 글자색 | 테두리색 | 의미 |
|---|---|---|---|
| 월~금 | #A6A6A6 | #333333 `--wc-border` | 평일 |
| 토 | #3D8BFF (`--wc-mode-coding` 값) | #183866 | 달력 관례(토=파랑) |
| 일 | #FF4D5E (`--wc-danger`) | #66202A | 달력 관례(일=빨강) |

색만으로 구분하지 않는다: 글자 자체가 요일이다. 공휴일 표시는 하지 않는다(달력 데이터 없음).
- 시각 동기화 전: 숫자 4개는 `-`(숫자 폰트에 `-` 추가), 색 #4D4D4D, 날짜 줄은 `시각 동기화 전`(한글 28px), 칩은 숨김.

### 2.5 번인 방지

**(1) 분마다 픽셀 이동(pixel orbit).** 분이 바뀌는 순간(숫자 라벨이 어차피 다시 그려지는 시점)에 `kFace` 를 8점 궤도 중 다음 점으로 옮긴다.

| 분 % 8 | dx | dy |
|---|---|---|
| 0 | 0 | 0 |
| 1 | +6 | -4 |
| 2 | +8 | +2 |
| 3 | +4 | +7 |
| 4 | -2 | +8 |
| 5 | -7 | +4 |
| 6 | -8 | -2 |
| 7 | -3 | -7 |

- 최대 ±8px, 숫자 획 두께(약 14px)의 절반 이상 이동 → 같은 픽셀이 연속 점등되는 시간이 줄고 가장자리 번인이 번진다.
- 이동 후 범위: 숫자 x 21~389, y 142~278, 날짜 y 284~340 — 상태줄(≤56)·배너(≥414)와 안 겹친다.
- 구현: `lv_obj_set_pos(kFace, dx, 56 + dy)` 한 번. 숫자 라벨 1~2개가 바뀌는 분에 맞춰 같이 일어나므로 추가 flush 거의 없음(old+new bbox 약 410×280, 40줄 버퍼 약 7번 flush, 분당 1회).
- 상태줄은 이동하지 않되 IDLE 단계에서 모드 점·이름을 숨긴다(고정 색 요소 제거).
- 이동은 초 틱 `:00` 에서만 하고 콜론 점멸과 같은 틱에서 처리한다(깜박임 겹침 방지).

**(2) 저휘도 단계(2.6절 IDLE).** 전체 밝기를 30%로 낮춤 + 초 점멸 중지 + 상태줄 최소화.

**(3) 고정 밝은 요소 최소화.** 배경 순검정, 테두리·틀·눈금 없음. 가장 밝은 면적은 숫자(#F2F2F2, 순백 아님).

**(4) 점멸로 분산.** 콜론 두 점은 ACTIVE 에서 1초마다 꺼졌다 켜져 해당 픽셀이 50%만 점등.

### 2.6 상태별 모습 (손목 들기 포함)

상태 기계: `OFF → ACTIVE → IDLE → OFF` (전원 상태는 기존 화면 꺼짐 정책을 따른다).

| 상태 | 진입 조건 | 밝기(사용자 설정 대비) | 보이는 것 | 갱신 |
|---|---|---|---|---|
| OFF | IDLE 22초 경과, 또는 손목 내림 | 패널 꺼짐 | 없음 | 없음 |
| ACTIVE | 손목 들기(IMU) / 아무 터치 / 모드 전환 직후 / 충전기 연결 | 100% | 전부(상태줄 포함), 콜론 점멸, 요일 칩 | 콜론 500ms 타이머, 분 경계 |
| IDLE | ACTIVE 후 터치 없이 8초 | **30%** | 숫자 4개 + 날짜 줄. 콜론 고정 점등, 상태줄은 배터리 %만(#777), 모드 점·이름·BLE 아이콘·배너 숨김(끊김은 ACTIVE 복귀 시 표시) | 분 경계 1회만 |
| 저전력(≤10%) | 배터리 ≤10% | ACTIVE 60%, IDLE 15% | 배터리 % 빨강 | IDLE→OFF 를 12초로 단축 |

- 손목 들기 응답: UI 는 미리 만들어 둔 상태. 깨우면 (1) 현재 분 숫자 재확인 setText(변경 없으면 no-op) (2) 밝기 0→100% 램프 120ms(4단계 레지스터 쓰기) (3) 콜론 타이머 시작. 렌더 비용은 사실상 0.
- ACTIVE 에서 가로 스와이프하면 기존 모드 전환 슬라이드(280ms)를 쓴다. 슬라이드 중 시계 본체는 `kRoot` 째로 움직인다.
- 시계 모드의 탭은 키를 보내지 않는다. 탭 = "깨우기"만. 상시 안내문은 없애고, 대신 첫 진입 6초만 힌트 `밀어서 모드 전환`(20px, #777)을 y414 에 둔다.
- 연결 끊김: 상태줄 BLE 아이콘 빨강 점멸 + 기존 배너(16,414,378,72). 배너는 ACTIVE 에서만. 끊긴 동안에도 시각은 정상 표시(시계는 독립 동작).
- 연결 대기(미페어링) 화면은 별도(`wRoot`)이며 이 문서 범위 밖.

### 2.7 모션 사양

| 동작 | 시간 | 방식 | 비용 |
|---|---|---|---|
| 콜론 점멸 | 500ms 켜짐 / 500ms 꺼짐 | `lv_obj_set_style_opa` 토글(14×14 두 개) | 아주 낮음 |
| 분 숫자 교체 | 즉시(0ms) | `lv_label_set_text`, 값이 같으면 호출 안 함 | 낮음 |

## 3. 색 토큰 (신규·변경)

`--wc-mode-clock` 계열이 tokens.css 에 정의돼 있지 않아 추가를 제안한다. 시계는 모드 중 가장 오래 켜져 있으므로 채도·밝기를 낮춘 차가운 회청색으로 한다(점등 면적이 작은 상태줄 점·이름에만 쓰임).

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--wc-mode-clock` | #8EA0B4 | 상태줄 모드 점·이름 |

## 4. 글꼴·플래시 비용

### 4.1 큰 숫자 글꼴 (필수)

| 항목 | 값 |
|---|---|
| 글자 | `0123456789` + `-`(동기화 전) = 11자(콜론은 원으로 그림) |
| 크기 | 128px (안 B 면 150px) |
| 글꼴 원본 | Pretendard Bold 또는 Montserrat Bold(둘 다 OFL). 한글과 숫자 모양을 맞추려면 Pretendard 권장 |
| 형식 | 4bpp(2bpp 는 절반이나 큰 글자 가장자리에 띠가 보임 → 4bpp 권장), 압축 켬 |
| 변환 | `lv_font_conv --font Pretendard-Bold.otf --size 128 --bpp 4 --format lvgl --range 0x30-0x39,0x2D --lv-font-name clock_digits_128 -o clock_digits_128.c` , sdkconfig 에 `CONFIG_LV_USE_FONT_COMPRESSED=y`(끄려면 `--no-compress`) |
| 글자당 비트맵 | 약 70×92 = 6,440px × 0.5B = 3.2KB 원본, 압축 후 약 2KB |
| **합계 플래시** | **약 20KB(4bpp 압축) / 약 36KB(비압축) / 2bpp 압축 약 11KB** |
| 150px(안 B) | 약 27KB(4bpp 압축) |
| RAM | 폰트 데이터는 플래시(XIP)에서 읽음 → RAM 0. 그리기 임시 버퍼는 기존 40줄 버퍼 재사용 |

위 숫자는 글리프 크기 산식(w×h×bpp/8, 압축률 약 0.6) 추정이다. `lv_font_conv` 로 실제 `.c` 크기를 확인해 마스터 문서 합계에 반영할 것(오차 ±30% 가능).

### 4.2 한글 서브셋 (날짜·요일·메시지)

한글 글리프 1개 비용 약 `w×h×bpp/8 × 0.65`(압축) + 글리프 표 약 8B.

| 크기 | 글자당 | 이 모드 필요 글자 | 합계 |
|---|---|---|---|
| 28px 4bpp | 약 330B | 월 화 수 목 금 토 일 시 각 동 기 전 + 숫자 0-9, `(` `)`, 공백 = 약 25자 | **약 8KB** |
| 20px 4bpp | 약 170B | 힌트·상태줄용: 밀 어 서 모 드 전 환 계 시 + 숫자 = 약 20자 | **약 3.5KB** |

- 이 모드만 보면 **한글 요일은 거의 공짜**(8KB). 숫자가 한글 폰트에 들어 있으므로 날짜 줄은 한 글꼴로 통일(영문 Montserrat 와 섞으면 기준선이 어긋남).
- 앱 전체(다른 디자이너 화면 포함) 규모 가늠:

| 범위 | 글자 수 | 20px 4bpp | 28px 4bpp |
|---|---|---|---|
| 시계 모드만 | 약 25 | 약 4KB | 약 8KB |
| 모든 모드 UI 문구 서브셋 | 약 300 | 약 55KB | 약 100KB |
| KS X 1001 완성형 전체 | 2,350 | 약 0.4MB | 약 0.8MB |

플래시 16MB 대비 전부 여유지만, **서브셋 도구가 `ui.cpp`/`screens.ts` 의 한글 문자열을 스캔해 `--symbols` 로 넘기게** 해서 누락(□ 표시)을 막는다(별도 작업).
- "오전/오후" 12시간제는 `오 후` 가 추가돼 +2자(약 0.7KB). 기본은 24시간제(교사 일과표와 일치), 12시간 선택은 후순위.

## 5. LVGL 9.5 구현 메모

```
kRoot  (lv_obj 410x446 @ (0,56), 투명, 스크롤·클릭 끔)     <- 모드 전환 슬라이드 대상
 +- kFace (lv_obj 410x446, 투명)                           <- 번인 이동 대상(분마다)
 |    +- kDig[4]  lv_label x4  (80x120, 가운데 정렬, font=clock_digits_128, #F2F2F2)
 |    +- kColon[2] lv_obj x2   (14x14 원, bg #A6A6A6, radius CIRCLE)
 |    +- kDateRow  lv_obj flex ROW center, gap 14
 |         +- kDate lv_label (font=ko_28, #A6A6A6)
 |         +- kDow  lv_obj 알약 52x40, border 2px -> lv_label (ko_28)
 +- kHint lv_label (font=ko_20, #777, 6초 후 HIDDEN)  <- kFace 밖(이동 안 함)
```

- 위젯 약 14개 = RAM 2~3KB(객체당 100~200B). 40줄 부분 버퍼 추가 없음.
- 스타일: 공용 `lv_style_t` 3개(숫자 글자, 보조 글자, 칩 테두리)만 만들어 재사용. 요일이 바뀔 때만 칩 테두리·글자색 변경(기존 setBorder 처럼 값 비교 후 호출).
- 갱신 규칙: `render()` 에서 값 비교 후 바뀐 라벨만 `lv_label_set_text`. 분 경계 외에는 `kColon` opa 토글(500ms `lv_timer`)만. IDLE 에서는 500ms 타이머 정지, 분 경계 1회(`lv_timer` 60s 정렬)만.
- 밝기: 패널 밝기 레지스터(CO5300 계열 0x51 예상, 실제 드라이버 확인 필요)로 제어. LVGL 색을 바꾸지 않음 → 렌더 비용 0.
- 그림자·그라데이션·알파 합성·`transform_scale` 사용 안 함. 번인 이동은 `lv_obj_set_pos`(scroll 아님).
- 숫자 폰트는 `LV_FONT_DECLARE(clock_digits_128)` 후 `lv_obj_set_style_text_font`. `LV_FONT_FMT_TXT_LARGE` 불필요(글리프 높이 92).
- 날짜 줄 flex 레이아웃은 날짜가 바뀔 때(하루 1회)만 다시 계산됨.
- 비용 요약: 분당 flush = 숫자 2셀 + 이동 1회(최대 약 7번 40줄), 초당 flush = 콜론 두 점(14×14) 2회(ACTIVE 에서만), IDLE 은 분당 1회뿐.

### 시뮬레이터(sim/) 반영

- `ClockView` 를 같은 구조로: `.watch-clock__face`(이동 컨테이너) 안에 숫자 셀 5개를 **고정 폭 인라인 블록(80/80/32/80/80)** 으로 둔다. `font-variant-numeric: tabular-nums` 에 의존하지 말고 셀 폭으로 맞춘다(펌웨어와 동일).
- 번인 이동은 `transform: translate(dx px, dy px)`, 궤도표 동일. 상태는 `data-clock-state="active|idle"` 로 두고 IDLE 은 `filter: brightness(.3)` 로 근사(실제 패널 밝기와 다름을 시뮬레이터 안내에 명시).
- 글꼴은 웹에서 Pretendard 를 쓰되 `--wc-font-family` 순서 유지. 요일 색·칩은 3절 토큰.
- 시각 소스는 기존 코어 상태를 그대로 씀. 시뮬레이터에 "손목 들기" 버튼이 있으면 ACTIVE 진입, 8초 뒤 IDLE, 30초 뒤 OFF 를 같은 타이밍으로 재현.

## 6. 확인 필요·리스크

1. 실제 AMOLED 에서 30% 밝기와 #F2F2F2 가독성(교실 조명). 25~40% 범위로 조정 가능해야 함. 설정 항목은 두지 않고 상수로 시작.
2. 128px 숫자 폰트의 실제 `.c` 크기: 4.1절 추정과 ±30% 오차 가능.
3. 번인 이동 시 상태줄이 고정이라 ACTIVE 에서 상태줄 요소가 같은 자리에 밝게 켜짐(IDLE 에서 최소화로 보완).
4. 숫자를 눌렀을 때의 동작은 정의하지 않음(깨우기만). 후속으로 "탭 = 12/24시간 전환" 등 검토 가능.
5. `--wc-mode-clock` 계열을 `design/tokens.css` 에 추가해야 함(이 문서는 다른 파일을 수정하지 않음).
