원본 토큰: `design/tokens.css` ↔ `firmware/main/ui.cpp` 상단 `C_*` 상수. **두 곳을 아래 6절 값으로 동시에 고친다.**

## 1. AMOLED 전력 모델

### 1.1 색별 상대 전력 (같은 면적 100% 점등, 순백 `#FFFFFF` = 1.00)

| 색 | 값 | 상대 전력 | 비고 |
| --- | --- | --- | --- |
| 순백 | `#FFFFFF` | 1.00 | 쓰지 않음 |
| text-1 | `#EEEEEE` | 0.85 | 글자는 면적이 작아 무방 |
| 시계 모래 | `#D9CDB4` | 0.56 | 시계 모드 기본색 |
| 시계 dim 자릿수 | `#9A8F7A` | 0.25 | 상시 표시 자릿수 |
| 파랑 | `#3D8BFF` | 0.55 | 실행. 청색 소자는 수명이 짧음 -> 면 채움 금지, 아이콘·선만 |
| 주황 | `#FF8A1F` | 0.35 | 발표 |
| 초록 | `#2FD07A` | 0.25 | 회의. 가장 효율 좋음 |
| surface-1 | `#181818` | 0.01 | 타일 면. 사실상 무료 |
| 주황 dim 면 | `#311808` | 0.01 | dim 면도 무료 |

결론: **글자·아이콘·테두리는 마음껏 색을 쓰고, 면은 dim(어두운 틴트)까지만.** 전력은 "밝은 색 x 면적"이라 타일을 모드색으로 꽉 채우는 순간이 최악이다.

### 1.2 면적 예산 (비검정 픽셀 비율, 410x502 = 205,820 px)

| 화면 | 목표 상한 | 근거 |
| --- | --- | --- |
| 시계 (기본, 가장 오래 켜짐) | **4%** (~8,200 px) | 큰 숫자 획 + 날짜. 타일 없음 |
| 발표 | 12% | 경과시간 숫자 + 좌우 힌트. 중앙·좌우는 검정 유지 |
| 실행 | 25% | 6타일이 dim 면(#181818)이라 전력상 무시, 아이콘·글자만 점등 |
| 회의 | 20% | 마이크 타일은 dim 면 + 큰 아이콘 |
| 설정 | 25% | 목록형 |
| 순간 플래시 | 0% | 전체 면 채움 금지 (10번 결정) |

타일 표면 `#181818` 은 검정 대비 1.2:1 로 거의 안 보인다. 괜찮다 -- 타일은 **아이콘+글자(대비 5:1 이상)** 로 식별되고, 경계는 2.2에서 보강한다.

### 1.3 시계 모드 전력 목표
상시 점등(손목 든 상태) 시계 모드 추정 면적 4% x 평균 상대 전력 0.4 = 풀 화이트 대비 약 1.6%. AOD(손목 내림) 는 **끄는 것이 기본**(화면 off), 옵션으로 켤 때 밝기 8%·자릿수 `#9A8F7A`·초 단위 갱신 없음(분 단위).

## 2. 모드 색 4종

각 모드 4단계 = 기본(base) / 눌림(strong) / 면(dim, 18% 합성) / 면 테두리(dim-border, 40%). 저휘도용 별도 값(dim-lo 26%, border-lo 55%)을 둔다. 전부 RGB565 로 정확히 표현되는 값으로 스냅했다.

| 모드 | base | strong | dim | dim-border | dim-lo (<=30%) | border-lo | 검정 대비(base) | dim 위 base | 검정 글자 on base |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| **시계 clock** (신규) | `#D6CEB5` | `#EDE5D0` | `#292421` | `#5A514A` | `#3A3531` | `#737163` | 13.3:1 | 9.7:1 | 13.3:1 |
| **발표 present** | `#FF8A21` | `#FFA552` | `#311808` | `#633908` | `#422408` | `#8C4D10` | 8.9:1 | 7.1:1 | 8.9:1 |
| **실행 launch** | `#3A8AFF` | `#6EA8FF` | `#081831` | `#193963` | `#102442` | `#214D8C` | 6.3:1 | 5.3:1 | 6.3:1 |
| **회의 meeting** | `#31CE7B` | `#5EDD98` | `#082419` | `#105531` | `#083521` | `#197142` | 10.4:1 | 8.1:1 | 10.4:1 |

(값은 565 스냅 후 hex. 기존 `#FF8A1F` 등과 시각 차이는 1~3 레벨로 눈에 띄지 않는다.)

### 2.1 시계 모드색을 이렇게 정한 이유
- 색상환 점유: 발표 주황 29° / 실행 파랑 216° / 회의 초록 148° / 잠금 보라 255° / 경고 노랑 48° / 끊김 빨강 353°. 모래색은 채도 18%의 40° 라 **색이라기보다 "기본 상태"** 로 읽힌다. 형광 청록(185°)은 파랑·초록 사이라 혼동 -> 기각.
- 청백색(#C9D1DC 안)은 파랑 성분 때문에 전력 0.66·번인 불리 -> 기각. 모래는 0.56, dim 자릿수는 0.25.
- 주황(발표)과 혼동 가능성: 채도 차이(88% vs 18%)와 **모드 이름 글자("시계"/"발표")** 가 항상 같이 표시되므로 색 단독 구분이 아님.
- 시계 모드는 base 로 큰 면을 채우지 않는다. 쓰임: 상태줄 모드 이름, 시각 숫자, 페이지 점(dot)의 활성 점.

### 2.2 모드 인디케이터 (가로 스와이프 전환 표시)
하단 페이지 점 4개: 지름 8px, 간격 16px, 중심 y=478. 활성 = 해당 모드 base, 비활성 = `#393939`. 점 영역 x=145~265 (4개x8 + 3x16 = 80px 폭, 중앙 정렬 x=165~245). 정적 요소라 번인 우려 -> 시계 모드에서는 비활성 3개만 항상, 활성 점은 위 9번 규칙(3초 후 dim)을 따른다.

## 3. 상태 색

모든 상태는 **색 + 모양 + 글자** 3중 표기 (색각 이상·햇빛 대비).

| 상태 | 색 (565 스냅) | dim 면 | 모양(필수) | 글자 | 검정 대비 | 표시 방식 |
| --- | --- | --- | --- | --- | --- | --- |
| 연결됨 | `#31CE7B` | — | 채운 점 지름 10px | (상태줄은 글자 없음, 설정에는 "연결됨") | 10.4:1 | 점만. 넓은 면 금지 |
| 연결 대기/재연결 중 | `#8C8A8C` (회색) | — | 속 빈 원 10px, 1초 주기로 점선 회전 대신 **불투명도 100/40% 교대** | "연결 대기" | 6.1:1 | 노랑·초록 아님: 중립은 문제 아님을 뜻함 |
| 끊김 | `#FF4D5A` | `#310C10` | 사선 걸린 BLE 아이콘 + 배너 | "연결 끊김" | 6.5:1 | 상단 배너 y=0~72, 2초 후 상태줄로 축소(점멸 1초 주기 2회만) |
| 잠금 | `#A58AF7` | `#211829` | 자물쇠 아이콘 | "잠금" | 7.7:1 | 전체화면 아님, 상태줄 + 중앙 토스트 |
| 경고(배터리 <=20%, 감도 경고) | `#FFD23A` | `#312408` | 배터리 아이콘 채움 20% + 퍼센트 글자 | "20%" | 14.7:1 | 노랑은 이 용도로만. 주황(발표)과 휘도 차 큼 |
| 위험(배터리 <=10%, 마이크 꺼짐) | `#FF4D5A` | `#310C10` | 빨간 아이콘 + 사선 | "음소거"/"10%" | 6.5:1 | 끊김과 같은 빨강이지만 문맥(위치)으로 구분 |

혼동 방지 규칙
- 빨강(끊김·위험)과 주황(발표): 색상 차 36°, 휘도 차 1.4배. 끊김 배너는 **항상 아이콘과 글자 동반**, 발표 모드에서도 배너는 danger-dim 면(`#310C10`) + 빨강 글자라 주황 면과 구분된다.
- 회의 초록과 연결 점: 점은 10px 점 하나만 허용. 회의 모드 상태줄에서는 모드 이름이 초록이므로, 연결 점을 모드 이름 오른쪽이 아닌 **BLE 아이콘 안**(아이콘 색 = text-2, 점 = 초록)에 넣는다.
- 색각 이상(적록): 초록 연결 / 빨강 끊김은 밝기 차(10.4 vs 6.5)와 모양(점 vs 사선 아이콘)이 있다.

- **검정 글자 on 모드 base 꽉 찬 면**(눌림·활성 칩): 시계 13.3 / 발표 8.9 / 실행 6.3 / 회의 10.4 / 경고 14.7 / 위험 6.5 -> 전부 AA 통과.

- 순 대비 비율은 한국어 글자 획이 가늘수록 체감이 낮다 -> **한글 글자는 굵기 600 이상**, 20~22px 은 700 권장(글꼴 담당과 합의 필요, 서브셋 용량 영향).
- 상태 정보를 색만으로 전달하지 않는다(3절).

## 5. 어두운 강의실 눈부심 대책

문제: 발표 중 교사의 손목이 청중·학생 시야 안에 있고, 불 끈 교실에서 AMOLED 는 작은 면이라도 매우 밝다(패널 100% 휘도는 어두운 방에서 눈에 띔).

### 5.1 밝기(패널 레지스터) 규칙

| 단계 | 값 | 용도 | 비고 |
| --- | --- | --- | --- |
| 낮음 | 20% (DCS 0x51 = 0x33) | 불 끈 강의실, 영상 상영 | 저휘도 팔레트 자동 적용 |
| 보통 | 45% (0x73) | 일반 교실(형광등) | 기본값 |
| 높음 | 100% (0xFF) | 복도·야외 | 전력 최대. 5분 후 자동으로 보통으로 복귀 |

모드별 기본 밝기(설정 "밝기"에서 사용자가 3단계 중 바꿀 수 있고, 모드별 기본은 위 표의 비율을 곱한다): 시계 30% / 발표 20% / 실행 45% / 회의 30%. 모드 전환 시 280ms 에 걸쳐 밝기를 선형 보간(레지스터 쓰기 8단계, 비용 미미).

자동 조도 센서는 없으므로 **수동 3단계 + 모드별 기본**이 현실적이다. 시뮬레이터는 같은 값을 `filter: brightness(0.2~1.0)` 로 근사한다(웹은 검정이 진짜 검정이 아니라 점등 차이만 표현됨, 주석 필수).

### 5.2 눈부심 회피 디자인 규칙
1. 순백·`#FFFFFF` 면 금지. 가장 밝은 글자 `#EEEEEE`, 발표 모드 숫자는 `#D6CEB5`(모래)로 더 부드럽게.
2. 화면 전체를 채우는 색 플래시 금지(10번). 암전(가운데 길게 누름)은 **밝기 레지스터 0 + 디스플레이 off**, 복귀 시 20%에서 시작해 300ms 램프(갑작스러운 밝기 점프 방지).
3. 발표 모드 숫자·힌트는 모드 base 가 아니라 **base 의 70% 휘도**(`#B26A19` 쪽)를 쓰는 옵션: 밝기 20% 에서 이미 충분하므로 기본은 base 유지, 대신 패널 밝기로 조절한다(토큰을 둘로 나누면 복잡).
4. 파랑(`#3A8AFF`)은 어두운 곳에서 눈이 가장 민감하게 반응(퍼킨제 이동). 실행 모드의 큰 면 사용 금지 — 아이콘·1~3px 선만.
5. 타일 눌림 피드백은 면색 `#181818 -> #2A2A2A`(밝아지는 폭 작음) + 아이콘 strong 색.

### 5.3 저휘도 팔레트 (밝기 <=30% 일 때 자동 교체)
교체 대상: 각 모드의 `dim`·`dim-border` 와 중립 `surface-1~3`. 글자색은 그대로.

| 토큰 | 기본 | 저휘도 (<=30%) |
| --- | --- | --- |
| surface-1 | `#181818` | `#212121` |
| surface-2 | `#212121` | `#2A2A2A` |
| surface-3 | `#2A2A2A` | `#393939` |
| border | `#393939` | `#4A4A4A` |
| 모드 dim | 18% 합성 | 26% 합성 (2절 표) |
| 모드 dim-border | 40% | 55% |

이유: 감마상 낮은 밝기에서 하위 레벨 구분이 사라진다(밝기 20% 에서 `#181818` 은 사실상 `#000`). 교체 비용은 상수 선택 한 번이라 0(`current_palette` 포인터만 바꾸고 화면을 다시 그린다).

### 6.3 팔레트 전환 구현 (LVGL)
- `static bool g_lowlight;` 밝기 설정이 바뀔 때(<=30%) 갱신. 모드색 접근 함수 `dim_of(mode)`, `border_of(mode)`, `surface1()` 가 이 플래그로 값을 고른다.
- 갱신: 보이는 화면만 `lv_obj_invalidate(screen)` 한 번. 스타일을 객체별로 바꾸지 말고, **공유 `lv_style_t` 객체의 색 속성을 `lv_style_set_bg_color` 로 바꾸고 `lv_obj_report_style_change(NULL)`** 한 번 호출 -> 전체 재그리기 1회(약 40줄 버퍼 x 13회 = 가벼움, 정지 화면에서만).
- 비용: 상수 테이블 +60B(플래시). RAM 영향 없음. 알파 합성 없음.

## 7. LVGL 구현 메모 (비용 중심)

| --- | --- | --- |
| 검정 배경 | `lv_obj_set_style_bg_color(scr, lv_color_hex(0x000000), 0)`, `bg_opa=COVER` | 0 |
| 타일 dim 면 | 단색 `bg_color = dim`, `bg_opa=COVER`, 반경 20, 테두리 1~2px `dimBorder` | 둥근 사각형 불투명 = 저비용. **그라데이션·그림자·`opa<255` 금지** |

## 9. 구현 순서 (권장)
1. `tokens.css` 와 `ui.cpp` 상수를 6절 값으로 교체하고 시계 모드 색 정의 누락(undefined `--wc-mode-clock*`) 해결.
2. 시계 화면 숫자 색을 `#9A8F7A` 상시 + 터치 3초 `#D6CEB5` 로, 순백 `#FFFFFF`(`strong`) 사용처 제거.
3. 밝기 3단계(설정)와 모드별 기본값, 램프, 저휘도 팔레트 플래그.
4. 시뮬레이터 `filter: brightness()` 와 `data-lowlight` 연결, 밝기 슬라이더 추가.
5. 실기 전력 실측(시계 5분, 발표 5분, 실행 5분 전류)으로 1.1 표의 효율 가정을 교정.

미결 사항: (1) 한글 글꼴 굵기 600~700 확정과 서브셋 용량(글꼴 담당). (2) 패널 밝기 레지스터 이름·범위(`CO5300` 드라이버 데이터시트 확인 필요, 0x51 은 MIPI DCS 표준이라 가정). (3) 야외 직사광에서 `#3A8AFF` 가독성은 실기에서 확인.
