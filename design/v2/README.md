## 0. 한 줄 원칙 (모든 화면 공통)

1. **배경 `#000000`, 면은 dim까지만.** 모드색을 꽉 채운 면은 작은 칩(암전 칩, 이름 칩 반전, 눌린 배지)에서만 쓴다.
2. **알파 합성·`transform_scale`·그림자·그라데이션·블러는 금지한다.** 눌림 scale 0.96, 교차 페이드, opacity 페이드, 덮개(scrim)를 모두 없앤다. "투명도 t"는 검정 위에 미리 섞은 **불투명 색**으로 바꾼다(`lv_color_mix`, `bg_opa = COVER`). 시뮬레이터도 CSS scale·transition을 쓰지 않는다.
3. **애니메이션은 계단식이다.** 값이 바뀔 때만 다시 그리고, 갱신 주기 상한은 33ms, 동시에 도는 애니메이션은 2개까지다.
4. **키는 손을 뗄 때 보낸다**(이동 12px 미만). 눌림 표시는 누르는 즉시(첫 프레임 35ms 이내) 그린다. 길게 누름은 모든 곳에서 **600ms**다.
5. **상태는 색만으로 나타내지 않는다.** 항상 모양이나 글자를 같이 쓴다.
6. **글자는 20px 이상 한글(Pretendard)로 쓴다.** 제품명(Zoom·Teams·Meet·Chrome·PPT·Excel·HWP·BLE·PC·IMU)만 영문으로 둔다.

- **한글 1자를 추가하면 네 크기 합쳐 약 0.86KB가 든다**(20px 126B, 24px 179B, 28px 241B, 32px 313B). KS X 1001 2,350자는 네 크기만으로도 약 2.1MB라 쓰지 않는다.

- 시뮬레이터는 같은 charset으로 woff2를 서브셋해서 쓴다(`pyftsubset`). 범위 밖 글자는 두부(▯)로 보이게 해서 누락을 먼저 찾는다.
