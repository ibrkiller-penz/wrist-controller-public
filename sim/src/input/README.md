## IMU 녹화 CSV 형식 (펌웨어 시리얼 녹화와 같은 형식)

펌웨어 2단계 6번 "IMU 읽기, 녹화 기능(시리얼로 CSV 출력)"이 이 형식으로 내보내고, 시뮬레이터 '녹화 재생'과 설정 화면 '녹화 재판정'이 읽는다.

```
# 주석 줄은 '#' 으로 시작 (기기·펌웨어 버전·자세 메모 등)
t_ms,gx,gy,gz,ax,ay,az
0,-1.50,-1.45,0.35,0.012,-0.020,0.998
10,-1.29,0.18,-0.98,0.011,-0.019,0.999
```

| 열 | 단위 | 뜻 |
| --- | --- | --- |
| `t_ms` | ms (정수 권장) | 측정 시각. 단조 증가. 녹화 시작 0 또는 부팅 후 시각 — 재생할 때 첫 샘플 기준으로 옮기므로 어느 쪽이든 된다 |
| `gx`,`gy`,`gz` | deg/s | 자이로 각속도, **센서 축 그대로**(바이어스 보정 전 원시값 권장 — 보정은 코어가 한다). 논리 축(yaw/pitch/roll) 변환은 `gesture.json imu.axisMap/axisSign` |
| `ax`,`ay`,`az` | g | 가속도. **선택 열** — 지금 판정에는 쓰지 않는다(손목 들면 화면 켜기 등 나중 용도). 없어도 읽힌다 |

- 구분자는 쉼표(세미콜론·탭도 읽음). UTF-8, 줄바꿈 LF/CRLF 모두 가능.
- 머리글이 있으면 열 이름(`t_ms`/`t`, `gx`, `gy`, `gz`)으로 찾으므로 열 순서가 달라도 된다. 머리글이 없으면 앞 네 열을 `t,gx,gy,gz` 로 본다.
- 숫자가 아닌 줄, 시각이 앞 줄보다 크지 않은 줄은 건너뛴다.
- 샘플링: `gesture.json imu.sampleRateHz`(100Hz) 권장. 코어 필터는 샘플 수가 아니라 dt 기반이라 간격이 조금 흔들려도 된다.
- 소수 둘째 자리(°/s), 셋째 자리(g)면 충분하다.

> ARCHITECTURE.md·`parseImuCsv` 첫 주석에는 머리글이 `t_ms,gx,gy,gz` 로 적혀 있다. 가속도 세 열은 **뒤에 붙는 선택 열**이라 두 표기는 서로 호환된다(통합 요청으로 문서 표기 통일을 요청함).

## 입력원

### 마우스 드래그 (담당 결정)

| 드래그 | 만드는 축(기본 axisMap) | 쓰임 |
| --- | --- | --- |
| 세로 dy (아래 +) | `gx` = pitch | 에어마우스 커서 Y |
| 가로 dx (오른쪽 +), 측면 버튼을 **누르지 않음** | `gy` = roll | 손목 튕김(오른쪽 = 바깥 = 다음) |
| 가로 dx, 측면 버튼을 **누르고 있음**(Space) | `gz` = yaw | 에어마우스 커서 X |

- 패널의 "가로 드래그" 선택으로 `roll` / `yaw` 고정도 가능. **Shift+드래그**는 그 순간 가로 축을 뒤집는다.
- 속도 → 각속도: 최근 30ms 포인터 이동 속도(px/s) × **0.5** (`DRAG_DPS_PER_PX_S`). 80px 를 80ms 에 휙 = 500°/s.
- 누르는 동안 10ms(100Hz)마다 샘플, 놓으면 점이 가운데로 돌아가고 300ms 동안 0 샘플(드리프트 없음 확인용).

### 폰 센서

- `DeviceMotionEvent.rotationRate`(deg/s): β→gx, γ→gy, α→gz. 표시용으로 DeviceOrientation β·γ(도)도 보여 준다.
- iOS 13+: 세그먼트 `폰 센서` 또는 `센서 권한 요청 · 켜기` 버튼 **click 안에서 동기적으로** `requestPermission()` 을 부른다.
- HTTPS(또는 localhost)가 아니면 켜지 않고 안내한다. 같은 Wi-Fi 의 `http://192.168…` 개발 서버로는 센서가 막히므로 배포된 HTTPS 주소로 시험한다.
- 2초 안에 값이 안 오면 "센서 값이 들어오지 않습니다" 안내(데스크톱 Chrome 은 인터페이스만 있고 값이 없다).

### 녹화 재생

- CSV 파일 열기 또는 샘플 두 개. 재생/일시정지, 정지(처음으로), 위치 슬라이더, 0.5×/1×/2×, 반복.
- 샘플 시각은 재생 시작 시각(`app.now()`)에 맞춰 옮긴다: `t = 시작시각 + (원래 t − 시작 위치) / 속도`. 1× 가 아니면 시간축이 바뀌어 튕김 지속시간 판정이 달라진다.

### 합성 동작 버튼

`바깥 튕김` `안쪽 튕김` `천천히 돌리기` `크게 천천히` `걷기` — 같은 재생 경로로 실시간 주입. 1단계 체크리스트 "튕김은 인식, 천천히 돌리기는 무시"를 손으로 재현하기 어려울 때 쓴다. 튕김 판정은 코어 규칙상 **발표 모드에서만** 한다.
